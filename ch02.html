2.1型態：資料長什麼樣子

強型別

C++ 是強型別語言：每個變數、每個物件在使用前都要先說清楚它的型態（type）。型態決定兩件事：

  1. 這筆資料在記憶體中佔多大的空間；
  2. 可以對它做哪些操作（整數可以相除取餘數，文字可以相接…）。

老師講義的分類：

類別 型態 例子
整數 short、int、long、long long 股數、天數、期數
浮點數（有小數） float、double 價格、利率、報酬率
字元 char 'A'、評等 'B'
布林 bool true／false：是否違約
空 void 「沒有回傳值」的函數
複合型態 陣列、指標、參考 本章後半、第 3 章
使用者定義型態 struct、union、enum、class 本章最後、第 7 章

佔多少記憶體：sizeof

記憶體的基本單位是位元組（byte，1 byte = 8 bits）。sizeof 告訴你某個型態或變數佔幾個位元組：

C++
#include <iostream>

int main() {
    std::cout << "char      : " << sizeof(char) << " byte\n";
    std::cout << "bool      : " << sizeof(bool) << " byte\n";
    std::cout << "short     : " << sizeof(short) << " bytes\n";
    std::cout << "int       : " << sizeof(int) << " bytes\n";
    std::cout << "long      : " << sizeof(long) << " bytes\n";
    std::cout << "long long : " << sizeof(long long) << " bytes\n";
    std::cout << "float     : " << sizeof(float) << " bytes\n";
    std::cout << "double    : " << sizeof(double) << " bytes\n";

    double price = 101.25;
    std::cout << "price 這個變數: " << sizeof(price) << " bytes\n";   // 也可以放變數
    return 0;
}

char      : 1 byte
bool      : 1 byte
short     : 2 bytes
int       : 4 bytes
long      : 8 bytes
long long : 8 bytes
float     : 4 bytes
double    : 8 bytes
price 這個變數: 8 bytes

long 在 64 位元的 Linux／Mac 是 8 bytes，在 Windows 是 4 bytes——同一個型態在不同平台大小可能不同，這也是為什麼要用 sizeof 確認，而不是死背。

能裝多大的數：numeric_limits

C++
#include <iostream>
#include <limits>

int main() {
    std::cout << "int       : " << std::numeric_limits<int>::min() << " ~ "
              << std::numeric_limits<int>::max() << "\n";
    std::cout << "unsigned  : 0 ~ " << std::numeric_limits<unsigned int>::max() << "\n";
    std::cout << "short     : " << std::numeric_limits<short>::min() << " ~ "
              << std::numeric_limits<short>::max() << "\n";
    std::cout << "long long : " << std::numeric_limits<long long>::min() << " ~ "
              << std::numeric_limits<long long>::max() << "\n";
    std::cout << "double 最大約 " << std::numeric_limits<double>::max()
              << "，有效位數約 " << std::numeric_limits<double>::digits10 << " 位\n";
    std::cout << "float  有效位數約 " << std::numeric_limits<float>::digits10 << " 位\n";
    return 0;
}

int       : -2147483648 ~ 2147483647
unsigned  : 0 ~ 4294967295
short     : -32768 ~ 32767
long long : -9223372036854775808 ~ 9223372036854775807
double 最大約 1.79769e+308，有效位數約 15 位
float  有效位數約 6 位
  • 4 bytes = 32 bits，可以表示 \(2^{32}\) 種值。int 有正負號，範圍是 \(-2^{31}\) 到 \(2^{31}-1\)（約正負 21 億）；unsigned int 沒有負數，範圍是 0 到 \(2^{32}-1\)（約 43 億）。
  • short 是 2 bytes（16 bits），範圍是 −32768～32767：負數比正數多一個，因為 0 佔掉了非負那一半的一個位置。
  • double 有約 15～16 位有效數字，float 只有約 6～7 位。金融計算幾乎一律用 double。
常見錯誤台積電市值裝得進 int 嗎？

2.6 兆元這種數字超過 int 的上限（約 21 億），要用 long long 或 double。整數超過上限會「溢位」，下一節有示範。

2.2變數：有名字的一塊記憶體

宣告、初始化、賦值

變數（variable）就是「有名字的一塊記憶體」，裡面放的值可以改變。每個變數有三個資訊：型態、位址（在記憶體的哪裡）、儲存的值。

C++
#include <iostream>

int main() {
    int shares = 1000;        // 定義並「初始化」：產生變數的同時給初值
    double price;             // 只定義，沒有給初值
    price = 101.5;            // 「賦值」：把新值放進已經存在的變數
    price = 102.0;            // 可以一直賦值
    std::cout << "市值 = " << shares * price << "\n";
    return 0;
}

市值 = 102000
  • 初始化只發生一次，在變數誕生的那一刻；賦值可以發生很多次。
  • 老師強調：一定要初始化。在函數裡宣告卻沒給初值的變數，內容是「上一個使用這塊記憶體的人留下的垃圾值」，讀它是未定義行為：
C++
#include <iostream>

int main() {
    int count;                       // 沒有初始化！
    std::cout << count << "\n";      // 印出不可預期的值
    return 0;
}

main.cpp:5:27: warning: ‘count’ is used uninitialized [-Wuninitialized]
    5 |     std::cout << count << "\n";      // 印出不可預期的值
      |                           ^~~~
main.cpp:4:9: note: ‘count’ was declared here
    4 |     int count;                       // 沒有初始化！
      |         ^~~~~
32765

編譯器（打開 -Wall）會警告 is used uninitialized。印出來的數字每台電腦、每次執行都可能不同（有時剛好是 0，別被騙了）。

四種初始化寫法

C++
#include <iostream>

int main() {
    int a = 10;      // 複製初始化（最常見）
    int b(20);       // 直接初始化（括號）
    int c{30};       // 列表初始化（大括號，C++11）
    int d = {40};    // 也是列表初始化
    int e{};         // 大括號空的：初始化成 0
    std::cout << a << " " << b << " " << c << " " << d << " " << e << "\n";
    return 0;
}

10 20 30 40 0

大括號 {} 有一個好處：不允許會遺失資料的轉換（narrowing）。例如把 3.14159 塞進 int：（若右邊是 double 變數而非字面值，g++ 預設只給警告，加上 -pedantic-errors 才會變成錯誤；其他編譯器如 clang、MSVC 直接報錯。）

C++
int main() {
    int a{3.1415926};   // 大括號：編譯器拒絕，避免悄悄遺失小數
    return 0;
}

    2 |     int a{3.1415926};   // 大括號：編譯器拒絕，避免悄悄遺失小數
      |           ^~~~~~~~~
main.cpp:2:9: warning: unused variable ‘a’ [-Wunused-variable]
    2 |     int a{3.1415926};   // 大括號：編譯器拒絕，避免悄悄遺失小數
      |         ^
C++
#include <iostream>

int main() {
    double pi = 3.1415926;
    int c(pi);          // 小括號：允許，但小數被直接砍掉
    int d = pi;
    std::cout << c << " " << d << "\n";
    return 0;
}

3 3

把 double 變成 int 是直接捨去小數（不是四捨五入），金融計算中算股數、張數時常常因此少一股。

命名規則

  • 由英文字母、數字、底線 _ 組成，不能以數字開頭，區分大小寫。
  • 不能使用關鍵字（int、return、class、for…）。
  • 好的名字讓程式自己會說話：rate、maturity_years、couponRate 比 a、x1 好得多。常見風格有 snake_case（底線）和 camelCase（駝峰），一個專案內統一就好。

Q1

選擇｜中初始化與賦值

關於初始化與賦值，下列何者正確？

  1. (A)初始化可以發生很多次，賦值只能一次
  2. (B)初始化在變數定義時發生一次，賦值可以很多次
  3. (C)沒有初始化的區域變數，值一定是 0
  4. (D)int x; 之後 x = 5; 這一行是初始化
答案 (B)

初始化在變數定義時發生一次，賦值可以很多次

解析

初始化是變數誕生時給的初值，只有一次；之後用 = 改值都是賦值。函數內未初始化的區域變數值是不確定的，不一定是 0。

Q2

預測輸出｜中捨去小數

下面程式會印出什麼？

C++
#include <iostream>
int main() {
    double budget = 100000;
    double price = 337.5;
    int lots = budget / price;      // 可以買幾股
    std::cout << lots << "\n";
}
答案
296

解析

100000 / 337.5 = 296.296…，存進 int 時直接捨去小數，得到 296（不是四捨五入）。

Q3

找錯｜中大括號初始化

為什麼 int shares{1500.0 / 7}; 無法編譯，而 int shares = 1500.0 / 7; 可以？要怎麼寫才能兩者都明確表示「我就是要捨去小數」？

答案

大括號初始化不允許「縮窄轉換」（double → int 會遺失小數），所以編譯器拒絕；= 允許隱性轉換，只會給警告或什麼都不說。要明確表示捨去，用強制轉換：int shares{static_cast<int>(1500.0 / 7)};。

C++
#include <iostream>
int main() {
    int shares{static_cast<int>(1500.0 / 7)};
    std::cout << shares << "\n";
}

214

解析

static_cast<目標型態>(值) 是 C++ 建議的轉換寫法（第 4 章詳細介紹），讓讀程式的人一看就知道這裡是刻意轉型。

2.3整數與浮點數的陷阱

整數除法

C++
#include <iostream>

int main() {
    std::cout << 7 / 2 << "\n";        // 兩個整數相除：結果是整數 3
    std::cout << 7 % 2 << "\n";        // % 取餘數：1
    std::cout << 7.0 / 2 << "\n";      // 只要有一個是浮點數：3.5
    int days = 45;
    std::cout << days / 365 << "  " << days / 365.0 << "\n";   // 0 和 0.123...
    return 0;
}

3
1
3.5
0  0.123288

計算「持有天數 / 365」這種年化比例時，兩邊都是整數就會得到 0——非常常見的 bug。寫成 365.0 或先轉成 double。

整數溢位

C++
#include <iostream>

int main() {
    int big = 2147483647;            // int 的最大值
    std::cout << big + 1 << "\n";    // 溢位：變成很大的負數
    long long safe = 2147483647LL;
    std::cout << safe + 1 << "\n";   // long long 沒問題
    return 0;
}

-2147483648
2147483648

有號整數溢位在 C++ 是「未定義行為」，實際上通常會繞回最小值。市值、成交金額、以「分」為單位的金額，都要注意是否超過 int 的範圍。

signed 與 unsigned 不要混用（老師的練習）

C++
#include <iostream>

int main() {
    unsigned u = 10, u2 = 42;
    std::cout << u2 - u << "\n";     // 32
    std::cout << u - u2 << "\n";     // 不是 -32！
    int i = 10, i2 = 42;
    std::cout << i2 - i << "\n";     // 32
    std::cout << i - i2 << "\n";     // -32
    std::cout << i - u << "\n";      // int 和 unsigned 混用：int 被轉成 unsigned
    std::cout << u - i << "\n";      // 0
    return 0;
}

32
4294967264
32
-32
0
0

unsigned 沒有負數，10 − 42 會「繞一圈」變成 \(2^{32}-32\) = 4294967264。更危險的是 int 和 unsigned 一起運算時，int 會被自動轉成 unsigned，所以 i - u 也變成一個超大的數。老師的提醒：同一條算式不要混用 signed 與 unsigned。

浮點數不是精確的

C++
#include <iostream>
#include <iomanip>

int main() {
    double a = 0.1 + 0.2;
    std::cout << std::setprecision(17) << a << "\n";
    std::cout << std::boolalpha << (a == 0.3) << "\n";       // false！
    float f = 12.34567291234987654321;
    double d = 12.34567291234987654321;
    std::cout << f << "\n" << d << "\n";                     // float 精度明顯較差
    return 0;
}

0.30000000000000004
false
12.345672607421875
12.345672912349876
  • 電腦用二進位存小數，0.1 無法被精確表示（就像 1/3 無法用有限的十進位小數表示），所以 0.1 + 0.2 不會剛好等於 0.3。
  • 不要用 == 比較兩個浮點數，要用「差距小於某個很小的數」：std::abs(a - 0.3) < 1e-12。
  • std::boolalpha 讓 bool 印成 true/false 而不是 1/0。
  • float 只有約 7 位有效數字，第 8 位以後就不準了；這也是金融用 double 的原因。
金融應用錢要怎麼存

定價、風險這類「模型計算」用 double 沒問題（本來就是近似）。但會計帳、交易撮合這種「一分錢都不能差」的系統，常把金額存成以最小單位計的整數（例如以「分」為單位的 long long），或使用專門的十進位數型別，避免浮點誤差累積。

Q3

選擇｜中比較浮點數

要判斷 double 變數 x 是否「等於」0.3，下列何者最恰當？

  1. (A)x == 0.3 && x != 0
  2. (B)x = 0.3; x == 0.3

Q4

寫程式｜中年化報酬

某股票買進價 120 元、賣出價 132 元，持有 73 天。寫程式計算持有期間報酬率與年化報酬率（單利，一年以 365 天計），兩者都用百分比、2 位小數印出。注意不要掉進整數除法的陷阱。

答案
C++
#include <iostream>
#include <iomanip>

int main() {
    double buy = 120, sell = 132;
    int days = 73;
    double hpr = (sell - buy) / buy;          // 持有期間報酬
    double annual = hpr * 365.0 / days;       // 年化（單利）
    std::cout << std::fixed << std::setprecision(2);
    std::cout << "持有期間報酬率：" << hpr * 100 << "%\n";
    std::cout << "年化報酬率：" << annual * 100 << "%\n";
}

持有期間報酬率：10.00%
年化報酬率：50.00%

解析

365.0 / days 讓除法用浮點數計算；若寫成 365 / days 會得到整數 5（剛好整除時沒差，但換成 70 天就錯了）。

2.4常數與字面值

字面值

直接寫在程式裡的值叫字面值（literal）：

C++
#include <iostream>

int main() {
    int dec = 250;                 // 十進位
    int bin = 0b11111010;          // 二進位（C++14）：0b 開頭
    int oct = 0372;                // 八進位：0 開頭（小心！）
    int hex = 0xFA;                // 十六進位：0x 開頭
    std::cout << dec << " " << bin << " " << oct << " " << hex << "\n";

    long long notional = 2'600'000'000'000LL;   // C++14 可以用 ' 分隔位數，LL 代表 long long
    double rate = 1.75e-2;                       // 科學記號：1.75 × 10^-2
    float f = 3.14f;                             // f 結尾代表 float
    unsigned u = 42u;                            // u 結尾代表 unsigned
    std::cout << notional << " " << rate << " " << f << " " << u << "\n";
    return 0;

2.6變數與記憶體：位址

記憶體像一排有門牌的置物櫃

電腦記憶體可以想成一長排置物櫃，每一格是 1 byte，每一格都有編號——這個編號就是位址（address）。定義一個 int 變數，就是向系統借了連續 4 格；變數名代表這一段的起始位址，型態決定這一段有多長。

用 &（取址運算子）可以看到變數的位址：

C++
#include <iostream>

int main() {
    int shares = 1000;
    double price = 101.5;
    char grade = 'A';
    std::cout << "shares 的值 = " << shares << "，位址 = " << &shares << "\n";
    std::cout << "price  的值 = " << price  << "，位址 = " << &price << "\n";
    std::cout << "grade  的位址 = " << static_cast<void*>(&grade) << "\n";
    return 0;
}

shares 的值 = 1000，位址 = 0x7ffe26036c8c
price  的值 = 101.5，位址 = 0x7ffe26036c90
grade  的位址 = 0x7ffe26036c8b
  • 位址用十六進位顯示（0x 開頭），每次執行可能不同——作業系統每次分配的位置不一樣。
  • char 的位址要轉成 void* 才會印出位址，否則 cout 會把它當成字串去印（第 3 章字元陣列會說明）。

為什麼要在意位址

在 R 裡你幾乎不用想記憶體；但 C++ 讓你直接操作位址，這帶來兩件事：

  1. 效率：傳一個很大的資料（例如一百萬筆報酬率）給函數時，可以只傳「它在哪裡」（位址，8 bytes），不用整份複製。
  2. 共享與修改：多個地方可以指向同一份資料，一個地方改了，大家都看得到。

這就是接下來的參考和指標。

2.7參考：替變數取別名

定義參考

參考（reference）就是別名：給一個已經存在的變數另一個名字。宣告時在型態後面加 &：

C++
#include <iostream>

int main() {
    double price = 100.0;
    double &p = price;        // p 是 price 的別名（參考）
    p = 105.5;                // 透過別名修改，等於改 price
    std::cout << "price = " << price << "，p = " << p << "\n";
    std::cout << "位址相同嗎？" << (&price == &p) << "\n";
    return 0;
}

price = 105.5，p = 105.5
位址相同嗎？1
  • double &p = price;：p 和 price 是同一塊記憶體的兩個名字（位址相同）。
  • 參考本身不是物件，不另外佔一塊記憶體，只是「綁定」在原來的物件上。

參考的規則

2.8指標：存放位址的變數

指標是什麼

指標（pointer）是一個變數，它存放的值是另一個變數的位址。用置物櫃比喻：普通變數的櫃子裡放的是「東西」，指標的櫃子裡放的是一張紙條，寫著「東西在第幾號櫃子」。

C++
#include <iostream>

int main() {
    double price = 101.5;
    double *ptr = &price;      // ptr 是「指向 double 的指標」，存放 price 的位址

    std::cout << "price 的位址 : " << &price << "\n";
    std::cout << "ptr 的值      : " << ptr << "\n";      // 和上一行一樣
    std::cout << "*ptr          : " << *ptr << "\n";     // 解參考：到那個位址拿東西
    *ptr = 99.0;                                        // 透過指標修改 price
    std::cout << "price 變成    : " << price << "\n";
    std::cout << "ptr 自己的位址: " << &ptr << "，大小 " << sizeof(ptr) << " bytes\n";
    return 0;
}

price 的位址 : 0x7ffcb5ff4bc8
ptr 的值      : 0x7ffcb5ff4bc8
*ptr          : 101.5
price 變成    : 99
ptr 自己的位址: 0x7ffcb5ff4bd0，大小 8 bytes

兩個符號、兩種角色（老師特別提醒要看上下文）：

出現在哪 * &
宣告中 double *ptr：ptr 是指標 double &r = x：r 是參考
運算式中 *ptr：解參考，取指向的東西 &x：取 x 的位址
  • 指標本身是物件：有自己的位址（&ptr）、自己的大小（64 位元系統上 8 bytes，不管指向什麼型態）。所以可以有「指標的指標」，但沒有「參考的參考」。
  • 指標的型態要和指向的物件一致：int* 只能指向 int。
  • 指標可以改指向別的物件（參考不行）。

指標 vs 參考

參考 T& 指標 T*
本質 別名，不是物件 獨立的物件，存位址
一定要初始化 是 否（但強烈建議）
可以改綁／改指 不行 可以
可以是「空的」 不行 可以（nullptr）
取值寫法 直接用名字 *ptr

老師的說法：參考是指標「更安全、更方便」的版本。能用參考就用參考；需要「可以為空」或「要改指向」時才用指標。

空指標與指標的狀態

C++
#include <iostream>

int main() {
    double *p = nullptr;          // 空指標：不指向任何東西（C++11）
    if (p == nullptr) {
        std::cout << "p 目前沒有指向任何東西\n";
    }
    double rate = 0.03;
    p = &rate;                    // 改指向 rate
    if (p) {                      // 非空指標轉成 bool 是 true
        std::cout << "現在指向的值：" << *p << "\n";
    }
    return 0;
}

p 目前沒有指向任何東西
現在指向的值：0.03

指標的值只會是四種狀態之一：(1) 指向一個物件；(2) 指向某物件「緊接著的下一個位置」（陣列走到尾端時）；(3) 空指標 nullptr；(4) 無效指標（例如沒初始化、或指向已經被釋放的記憶體）。對無效指標解參考會讓程式崩潰或產生怪結果，而且編譯器不會幫你檢查。所以：

重點指標的好習慣

宣告指標時一律初始化，不知道要指向誰就給 nullptr；解參考之前先確定不是空的。舊程式裡的 NULL 或 0 也代表空指標，新程式用 nullptr。

指標的指標

C++
#include <iostream>

int main() {
    int x = 100;
    int *ptr = &x;
    int **ptr2 = &ptr;          // ptr2 存放 ptr 的位址
    std::cout << "x     = " << x << "\n";
    std::cout << "ptr   = " << ptr << "，*ptr = " << *ptr << "\n";
    std::cout << "ptr2  = " << ptr2 << "，*ptr2 = " << *ptr2 << "，**ptr2 = " << **ptr2 << "\n";
    return 0;
}

x     = 100
ptr   = 0x7ffc40b08214，*ptr = 100
ptr2  = 0x7ffc40b08218，*ptr2 = 0x7ffc40b08214，**ptr2 = 100

*ptr2 拿到的是 ptr（一個位址），再 * 一次 **ptr2 才拿到 x 的值 100。

void* 指標

C++
#include <iostream>

int main() {
    double obj = 3.14;
    void *pv = &obj;                                   // void* 可以存任何型態的位址
    std::cout << *static_cast<double*>(pv) << "\n";    // 要先轉回正確的型態才能解參考
    return 0;
}

3.14

void* 只知道「位址」，不知道那裡放的是什麼型態，所以不能直接解參考。現代 C++ 很少需要它，看到能認得就好。

從右往左讀複雜的宣告

老師的技巧：離變數名稱最近的符號影響最直接，從右往左讀。

C++
#include <iostream>

int main() {
    int i = 42;
    int *p;               // p 是一個指標，指向 int
    int *&r = p;          // 從右往左：r 是一個參考（&），綁定的是 int*（指向 int 的指標）
    r = &i;               // 透過 r 讓 p 指向 i
    *r = 0;               // 透過 r 解參考，把 i 改成 0
    std::cout << "i = " << i << "，*p = " << *p << "\n";
    return 0;
}

i = 0，*p = 0

2.9const 與指標、右值參考

指向常數的指標 vs 常數指標

const 和指標放在一起有兩種意思，老師用 Top-Level 和 Low-Level 區分：

C++
#include <iostream>

int main() {
    double rate = 0.02, other = 0.05;

    const double *p1 = &rate;    // 指向「常數」的指標（Low-Level const）：不能透過 p1 改值
    p1 = &other;                 // 可以改指向
    // *p1 = 0.1;                // 錯誤

    double *const p2 = &rate;    // 「常數指標」（Top-Level const）：p2 永遠指向 rate
    *p2 = 0.03;                  // 可以透過 p2 改值
    // p2 = &other;              // 錯誤

    const double *const p3 = &rate;   // 兩者皆是：不能改指向，也不能透過它改值
    std::cout << *p1 << " " << *p2 << " " << *p3 << "\n";
    return 0;
}

0.05 0.03 0.03

從右往左讀：double *const p2 → p2 是 const 的（const 緊鄰 p2），它是指標，指向 double。const double *p1 → p1 是指標，指向 const double。

  • Top-Level const：物件本身是 const（指標本身不能改）。
  • Low-Level const：指向／綁定的物件是 const（不能透過它改）。

const 參考：唯讀的別名

C++
#include <iostream>

int main() {
    double nav = 15.32;
    const double &view = nav;    // 唯讀別名：可以看、不能改
    nav = 15.40;                 // 原變數自己可以改
    std::cout << view << "\n";   // 看到的是最新值 15.4
    const double &tmp = 1.5 * 2; // const 參考可以綁定運算結果（臨時物件）
    std::cout << tmp << "\n";
    return 0;
}

15.4
3

const 參考是傳大型資料給函數的標準寫法：不複製（快）、又保證函數不會改到原資料（安全）。第 5、7 章會一直出現 const std::vector<double>&、const std::string&。

右值參考 &&（C++11，先認識）

  • 左值：有名字、有位址、可以出現在 = 左邊的東西，例如變數 x。
  • 右值：臨時的值，例如 3、x * 100、函數回傳的暫時結果，用完就消失。
C++
#include <iostream>
#include <string>

int main() {
    int i = 10;
    int &&r1 = 3;              // 右值參考綁定右值（字面值）
    int &&r2 = i * 1000;       // 綁定運算產生的臨時值
    r1 = 5;                    // 綁定後可以修改
    std::cout << r1 << " " << r2 << "\n";
    // int &&r3 = i;           // 錯誤：右值參考不能綁定左值
    return 0;
}

5 10000

右值參考的目的是效率：對「反正要消失的臨時物件」，與其複製一份，不如直接把它的內容「搬走」（move）。這是現代 C++ 的重要機制，第 7 章講物件複製時會再看到；現在只要知道 & 綁定有名字的東西、&& 綁定臨時的東西。

Q2

簡答｜中const 參考的用途

為什麼函數參數常寫成 const std::vector<double> &returns，而不是 std::vector<double> returns 或 std::vector<double> &returns？

答案

寫成 std::vector<double> returns（傳值）會把整份資料複製一次，資料大時很慢；寫成 std::vector<double> &returns（一般參考）不複製，但函數可能不小心修改呼叫端的資料。const 參考兩者兼顧：不複製、又保證函數只能讀不能改，也能接受臨時物件。

2.10自訂型態：struct、enum、union

struct：把相關的資料打包

一張債券有面額、票面利率、到期年數……分散成好幾個變數很亂。結構（struct）把它們打包成一個新型態：

C++
#include <iostream>
#include <cmath>

struct Bond {
    double face;          // 面額
    double coupon_rate;   // 票面利率（年）
    int years;            // 到期年數
};                        // 注意：結構定義結尾要有分號！

int main() {
    Bond b1 = {100.0, 0.02, 5};    // 依成員順序初始化
    Bond b2;
    b2.face = 1000;                // 用「.」存取成員
    b2.coupon_rate = 0.035;
    b2.years = 10;

    double y = 0.03;               // 殖利率
    double price = 0;
    for (int t = 1; t <= b1.years; t++) {
        double cf = b1.face * b1.coupon_rate;      // 每年票息
        if (t == b1.years) cf += b1.face;           // 最後一年加上本金
        price += cf / std::pow(1 + y, t);
    }
    std::cout << "b1 價格 = " << price << "\n";
    std::cout << "b2 面額 = " << b2.face << "，sizeof(Bond) = " << sizeof(Bond) << "\n";
    return 0;
}

b1 價格 = 95.4203
b2 面額 = 1000，sizeof(Bond) = 24
  • struct Bond { ... }; 定義一個新型態 Bond，之後 Bond b1; 就像 int x; 一樣用。
  • 用 . 存取成員：b1.face。
  • sizeof(Bond) 是 24 而不是 8 + 8 + 4 = 20：編譯器會在成員之間或尾端補空白（對齊，alignment），讓存取更快。
  • 老師提醒：struct 是 class 的基礎。第 7 章的類別就是「資料＋操作資料的函數」打包在一起。

結構可以套結構，也可以有指向結構的指標（用 -> 存取成員）：

C++
#include <iostream>
#include <string>

struct Date { int year, month, day; };

struct Trade {
    std::string ticker;
    int shares;
    double price;
    Date trade_date;          // 結構裡放結構
};

int main() {
    Trade t = {"2330", 1000, 1015.0, {2026, 11, 13}};
    Trade *pt = &t;           // 指向結構的指標
    pt->shares += 500;        // 指標用 ->，等於 (*pt).shares
    std::cout << t.ticker << " " << t.shares << " 股，成交日 "
              << t.trade_date.year << "/" << t.trade_date.month << "/" << t.trade_date.day << "\n";
    return 0;
}

2330 1500 股，成交日 2026/11/13

enum：用名字取代代號

C++
#include <iostream>

enum Rating { AAA, AA, A, BBB, BB };          // 傳統 enum：值依序是 0, 1, 2, 3, 4
enum class Side { Buy = 1, Sell = -1 };       // C++11 的 enum class（建議）

int main() {
    Rating r = BBB;
    std::cout << "BBB 的代碼 = " << r << "\n";
    std::cout << "投資等級？" << (r <= BBB) << "\n";

    Side s = Side::Sell;
    int qty = 100;
    int signed_qty = qty * static_cast<int>(s);   // enum class 要明確轉型才能當整數用
    std::cout << "部位變動 = " << signed_qty << "\n";
    return 0;
}

BBB 的代碼 = 3
投資等級？1
部位變動 = -100
  • 列舉讓程式用 BBB、Side::Sell 這種有意義的名字，而不是神秘的數字。
  • 傳統 enum 的值預設從 0 開始依序加 1，也可以自己指定（Red = 7 之後的成員會接著 8）。
  • enum class（有範圍的列舉）要寫 Side::Sell，也不會自動變成整數，比較不會出錯，現代 C++ 建議用它。

union：同一塊記憶體輪流使用（認識即可）

C++
#include <iostream>

union Value {
    int i;
    double d;
};

int main() {
    Value v;
    v.i = 42;
    std::cout << "sizeof(Value) = " << sizeof(Value) << "\n";   // 取最大成員的大小
    v.d = 3.5;                                               // 之後只有 d 有效
    std::cout << v.d << "\n";
    return 0;
}

sizeof(Value) = 8
3.5

union 的所有成員共用同一塊記憶體，同一時間只有最後被賦值的那個有效。用在記憶體非常吃緊的場合；一般金融程式很少用，現代 C++ 有更安全的 std::variant。

2.11本章小結

  • C++ 是強型別語言：整數 int／long long、浮點數 double（金融首選）、字元 char、布林 bool；用 sizeof、numeric_limits 查大小與範圍。
  • 變數要初始化；{} 初始化可防止縮窄轉換；double 轉 int 是捨去。
  • 陷阱：整數除法、整數溢位、signed／unsigned 混用、浮點數不能用 == 比較。
  • 字面值：0b／0／0x 進位、'a' 字元 vs "a" 字串（多一個 '\0'）、bool 中 0 為 false；const 不能改、constexpr 編譯期求值。
  • std::cin >> 讀入資料。
  • 記憶體與位址：&x 取址；參考 T& 是別名（必須初始化、不能改綁）；指標 T* 存位址（*p 解參考、nullptr 空指標、可以改指向）。
  • const 與指標：const T* 不能透過它改值（Low-Level）、T* const 不能改指向（Top-Level）；const T& 是唯讀別名。&& 右值參考綁定臨時物件，用於 move。
  • struct 打包資料（. 與 ->）、enum class 取有意義的名字、union 共用記憶體。
