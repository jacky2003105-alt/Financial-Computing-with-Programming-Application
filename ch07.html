這一章進入本學期的核心：類別（class）。到目前為止，資料（變數、struct）和操作資料的程式（函數）是分開的；類別把兩者打包成一個自己定義的新型態——例如 Bond 不只記得面額和票面利率，還知道怎麼算自己的價格與存續期間。本章對應講義六的前半：成員變數與成員函數、public／private、建構函數（含 explicit 與初始化列表）、const 成員函數、this、static 成員、運算子重載，以及物件的複製與解構。下一章再談繼承與多型。

7.1類別與物件

藍圖與實體

  • 類別（class）：使用者自己定義的型態，是一張「藍圖」，描述這種東西有哪些屬性（成員變數）和行為（成員函數）。
  • 物件（object）：依照藍圖建立出來的實體（instance）。建立物件的動作叫實例化；只有實例化時，才會真的在記憶體中配置空間。
  • 每個物件都有自己的一份成員變數；同一個類別的不同物件彼此獨立。

老師介紹物件導向的三個核心概念：

概念 意思
封裝（encapsulation） 把資料和操作資料的程式包在一起，隱藏實作細節，只開放必要的介面
繼承（inheritance） 新類別沿用既有類別的特性，避免重複撰寫（第 8 章）
多型（polymorphism） 用共同的介面表現不同的行為（第 8 章）

C 語言沒有類別，這是 C++ 最大的擴充。

老師上課怎麼說程序式 vs 物件導向

學期第一堂課，老師先比較兩種寫程式的方式：以前寫 R、Python 多半是「程序式」——要完成一個任務就從頭寫到尾：載入套件、準備市場資料、帶進模型計算、輸出結果。這樣很快能拿到答案，但彈性很小：換一個模型、換一種數值方法，就得在程式中間大改。物件導向用類別把資料和操作包起來、用繼承重用程式碼，維護比較容易、彈性比較高；之後的模板又是第三種寫法（泛型），現代的程式庫（包括 QuantLib）大量使用模板。老師也提醒：類別只是「藍圖」，沒有佔記憶體；按照藍圖產生出來的物件才真的在記憶體中佔空間——就像第 2 章 int 佔 4 bytes、double 佔 8 bytes 一樣。

第一個類別：老師的 Time

C++
#include <iostream>

class Time {
public:                       // 以下成員對外公開
    int Hour;                 // 成員變數（屬性）
    int Minute;
    int Second;

    void initTime(int h, int m, int s) {   // 成員函數（行為）
        Hour = h;             // 成員函數可以直接使用自己的成員變數
        Minute = m;
        Second = s;
    }
};                            // 類別定義結尾要有分號！

int main() {
    Time myTime;                          // 實例化：建立一個 Time 物件
    myTime.initTime(11, 14, 5);           // 用「.」呼叫成員函數
    std::cout << myTime.Hour << ":" << myTime.Minute << ":" << myTime.Second << "\n";

    Time *pt = &myTime;                   // 指向物件的指標
    pt->Minute = 30;                      // 用「->」存取
    std::cout << myTime.Minute << "\n";
    return 0;
}

  • 類別本身就是一個作用域：成員函數裡可以直接用 Hour，它指的就是「呼叫這個函數的那個物件的 Hour」。

public、private 與 class／struct 的差別

C++
#include <iostream>

class Account {
public:                                   // 介面：外界可以使用
    void deposit(double amt) {
        if (amt <= 0) {
            std::cout << "存款金額必須為正\n";
            return;
        }
        balance += amt;
        log_count();
    }
    double get_balance() { return balance; }

private:                                  // 實作細節：只有類別自己的成員函數能用
    double balance = 0;
    int ops = 0;
    void log_count() { ++ops; }
};

int main() {
    Account a;
    a.deposit(5000);
    a.deposit(-100);
    std::cout << "餘額 " << a.get_balance() << "\n";
    // a.balance = 1e9;                   // 錯誤：balance 是 private
    return 0;
}

7.2把類別拆成 .h 與 .cpp

實務上，類別的定義放在標頭檔（檔名通常和類別同名，例如 MyTime.h），成員函數的實作放在原始檔（MyTime.cpp）。要使用這個類別的檔案就 #include "MyTime.h"：

C++ 檔案：MyTime.h
// MyTime.h：類別定義（介面）
#ifndef MYTIME_H
#define MYTIME_H

class Time {
public:
    int Hour;
    int Minute;
    int Second;
    void initTime(int h, int m, int s);     // 只有宣告
    void print();
};

#endif
C++ 檔案：MyTime.cpp
// MyTime.cpp：成員函數的實作
#include <iostream>
#include "MyTime.h"

void Time::initTime(int h, int m, int s) {  // Time:: 表示「這是 Time 的成員函數」
    Hour = h;
    Minute = m;
    Second = s;
}

void Time::print() {
    std::cout << Hour << ":" << Minute << ":" << Second << "\n";
}
C++
// main.cpp
#include "MyTime.h"

int main() {
    Time t;
    t.initTime(9, 30, 0);
    t.print();
    return 0;
}

9:30:0
  • 在類別外實作成員函數時，名稱前面要加 類別名::（作用域運算子），否則編譯器會以為那是一個普通函數。
  • 寫在類別定義內部的成員函數，會自動被視為 inline（第 5 章）；簡短的函數（像 getter）常直接寫在類別裡。
  • 老師提醒一個特殊之處：函數和變數在整個程式中只能定義一次，但類別定義可以出現在多個 .cpp 中（透過 include），只要內容一致——所以類別定義可以放在標頭檔。
老師上課怎麼說分離編譯：為什麼要 include 標頭檔

老師在 VS Code 示範：把 Time 的使用程式貼進 main 後，編譯器說它不認識 Time——因為 C++ 是分離編譯，每個 .cpp 各自獨立編譯，編譯 test.cpp 時必須透過 #include "MyTime.h" 讓它知道 Time 這張藍圖長什麼樣子（自己寫的標頭檔用雙引號，官方的用角括號）。接著老師把 initTime 的實作註解掉，只留宣告：只是少了一個函數，卻冒出十幾個錯誤。老師的建議：自己練習時就是要這樣做實驗——故意拿掉一行看會發生什麼，「程式能跑」不代表你懂了；看到幾十個錯誤也不要慌，可能只是一兩個根本原因。

7.3建構函數

讓物件一誕生就是正確的

initTime 的問題是：忘了呼叫它，物件的成員就是垃圾值。建構函數（constructor）解決這個問題——它是一個特殊的成員函數，名稱和類別相同、沒有回傳型態，在物件建立時由系統自動呼叫：

C++
#include <iostream>

class Time {
public:
    int Hour, Minute, Second;

    Time(int h, int m, int s) {        // 建構函數：名稱 = 類別名，沒有回傳型態（連 void 都不寫）
        Hour = h;
        Minute = m;
        Second = s;
        std::cout << "建構了 " << Hour << ":" << Minute << ":" << Second << "\n";
    }
};

int main() {
    Time t1(9, 30, 0);                 // 建立物件時就要給參數
    Time t2{13, 45, 30};               // 大括號也可以
    Time t3 = Time(15, 0, 0);
    return 0;
}

多個建構函數與預設建構函數

建構函數也可以重載：提供好幾種建立物件的方式。不帶參數的叫預設建構函數（default constructor）：

C++
#include <iostream>

class Time {
public:
    int Hour, Minute, Second;
    Time() {                                   // 預設建構函數
        Hour = 12; Minute = 59; Second = 59;
    }
    Time(int h, int m, int s) {
        Hour = h; Minute = m; Second = s;
    }
    void print() const { std::cout << Hour << ":" << Minute << ":" << Second << "\n"; }
};

int main() {
    Time a;              // 呼叫預設建構函數（注意：不要寫成 Time a(); ）
    Time b{};            // 也是預設建構函數
    Time c(8, 0, 0);
    a.print(); b.print(); c.print();
    return 0;
}

explicit：禁止偷偷轉換

只有一個參數的建構函數，會變成「從那個型態轉換成這個類別」的隱式轉換途徑：

C++
#include <iostream>

class Money {
public:
    double value;
    Money(double v) { value = v; }          // 沒有 explicit
};

void pay(Money m) { std::cout << "付款 " << m.value << "\n"; }

int main() {
    Money a = 100.0;      // 看起來像賦值，其實是用 100.0 呼叫 Money(double) 建立 a
    pay(250);             // 250 被偷偷轉成 Money 物件！
    a = 99;               // 99 先轉成臨時 Money，再賦值給 a
    std::cout << a.value << "\n";
    return 0;
}

付款 250
99

pay(250) 能編譯，但 250 是什麼？250 元？250 股？250 個基點？這種隱式轉換容易藏 bug。加上 explicit 就禁止它：

C++
class Money {
public:
    double value;
    explicit Money(double v) { value = v; }
};

void pay(Money) {}

int main() {
    Money ok(100.0);      // 正確：直接初始化，明確呼叫建構函數
    Money bad = 100.0;    // 錯誤：複製初始化需要隱式轉換
    pay(250);             // 錯誤：不能把 int 偷偷轉成 Money
    pay(Money(250));      // 正確：明確寫出來
    return 0;
}

成員初始化列表

建構函數有一種專門用來初始化成員的寫法：在參數列表後面加冒號，依序寫 成員(初值)：

C++
#include <iostream>
#include <string>

class Bond {
public:
    Bond(const std::string &id, double face, double coupon, int years)
        : id_(id), face_(face), coupon_(coupon), years_(years)   // 成員初始化列表
    {
        // 所有成員都在上面初始化完了，函數體可以是空的——但大括號一定要寫
    }
    void print() const {
        std::cout << id_ << "：面額 " << face_ << "，票面利率 " << coupon_ * 100
                  << "%，" << years_ << " 年\n";
    }
private:
    std::string id_;
    double face_;
    double coupon_;
    int years_;

7.4const 成員函數、mutable、this

const 成員函數：保證不改物件

在成員函數參數列表後加 const，表示這個函數不會修改物件的成員變數：

C++
#include <iostream>

class Position {
public:
    Position(int qty, double cost) : qty_(qty), cost_(cost) {}
    double market_value(double px) const { return qty_ * px; }        // const：只讀
    double pnl(double px) const { return (px - cost_) * qty_; }
    void add(int q, double px) {                                       // 非 const：會修改
        cost_ = (cost_ * qty_ + px * q) / (qty_ + q);
        qty_ += q;
    }
private:
    int qty_;
    double cost_;
};

int main() {
    Position p(1000, 50.0);
    p.add(500, 56.0);
    std::cout << "均價後損益 " << p.pnl(55.0) << "\n";

    const Position snapshot(2000, 30.0);                // const 物件
    std::cout << "市值 " << snapshot.market_value(31.0) << "\n";   // 可以呼叫 const 成員函數
    // snapshot.add(100, 31.0);                         // 錯誤：const 物件不能呼叫非 const 成員函數
    return 0;
}

市值 62000
  • const 物件（或 const 參考，例如函數參數 const Position &p）只能呼叫 const 成員函數。非 const 物件兩種都能呼叫。
  • 所以：凡是不修改物件的成員函數，一律加 const。忘了加的話，你的類別一傳進 const& 參數就什麼都不能做。
  • 宣告與定義（.h 和 .cpp）兩邊都要寫 const；普通函數（非成員函數）不能加 const。
老師上課怎麼說QuantLib 幾乎都加 const

老師打開 QuantLib 的 FloatingRateCoupon 原始碼：裡面所有的成員函數後面一個都不漏地加上了 const（例如回傳型態是 Real 的 accruedAmount() const；Real 是 QuantLib 為 double 取的別名，從數學「實數」的角度命名）。原因要從「成員函數是誰在呼叫」想起：如果物件被宣告為 const（或透過 const 參考傳進來），它唯一能呼叫的就是 const 成員函數——所以不改物件的函數一律加 const，物件才能在各種情況下被使用。老師也提醒：「const 和 mutable 這兩個要一起看」。

mutable：const 函數裡的例外

被 mutable 修飾的成員變數，即使在 const 成員函數中也能修改。典型用途是「不影響物件邏輯狀態」的東西，例如快取或計數：

C++
#include <iostream>
#include <cmath>

class Bond {
public:
    Bond(double coupon, int years) : coupon_(coupon), years_(years) {}
    double price(double y) const {                     // 邏輯上只是「查詢價格」
        ++calls_;                                      // 但想記錄被查詢幾次
        double p = 0;
        for (int t = 1; t <= years_; ++t) p += 100 * coupon_ / std::pow(1 + y, t);
        return p + 100 / std::pow(1 + y, years_);
    }
    int calls() const { return calls_; }
private:
    double coupon_;
    int years_;
    mutable int calls_ = 0;                            // const 函數也能改
};

int main() {
    const Bond b(0.03, 5);
    b.price(0.025);
    b.price(0.030);
    std::cout << "price 被呼叫 " << b.calls() << " 次，最新價格 " << b.price(0.035) << "\n";
    return 0;
}

this：指向「目前這個物件」

成員函數怎麼知道 Hour 是哪個物件的 Hour？因為每個（非 static）成員函數都有一個隱藏的參數 this——指向呼叫它的那個物件的指標。t.addHour(3) 在編譯器眼中大約是 Time::addHour(&t, 3)。

C++

public:
    Account &deposit(double amount) {
        balance += amount;
        return *this;                  // 回傳物件本身（的參考）
    }
    Account &withdraw(double amount) {
        balance -= amount;
        return *this;
    }
    Account &set_owner(const char *owner) {
        this->owner = owner;           // 參數和成員同名時，用 this-> 指明是成員
        return *this;
    }
    void show() const {
        std::cout << owner << " 餘額 " << balance << "（物件位址 " << this << "）\n";
    }
private:
    double balance = 0;
    const char *owner = "";
};

int main() {
    Account a;
    a.set_owner("Lin").deposit(1000).withdraw(200).deposit(50);   // 鏈式呼叫

    std::cout << "a 的位址      " << &a << "\n";
    return 0;

  • 回傳 *this 的參考，就能把呼叫串起來：a.deposit(1000).withdraw(200)（鏈式呼叫，method chaining）。老師講義的 mytime.rtnhour(3).rtnminute(5) 也是這樣。
  • 在一般成員函數中，this 的型態是 Time* const（不能改指向別的物件）；在 const 成員函數中是 const Time* const——這就是 const 成員函數不能改成員的原因。
老師上課怎麼說this 是哪一種 const？

老師在課堂上問：成員函數加上 const 之後，裡面的 this 是哪一種指標？先複習第 2 章：const int n 的 const 描述 n 本身不能改，是 top-level；指標與參考是存取資料的「第二條路（間接管道）」，low-level const 的意思是「不能透過這條間接管道去改」。this 本來就不能改指向別的物件（top-level const）；const 成員函數再加上一層 low-level const，於是不能透過 this 修改物件——這就是 const 成員函數改不了成員變數的原因。

  • this 是保留字，不能當變數名；static 成員函數沒有 this（下一節）。

7.5static 成員：屬於類別，不屬於物件

static 成員變數

一般成員變數每個物件各有一份；加上 static 的成員變數整個類別只有一份，所有物件共用：

C++
#include <iostream>

class Trade {
public:
    Trade(double amt) : id_(++next_id_), amt_(amt) { ++count_; }
    ~Trade() { --count_; }                       // 解構函數（7.7 節）：物件消失時執行
    int id() const { return id_; }
    static int count() { return count_; }        // static 成員函數
    static int next_id_;                         // 宣告（public 只是為了示範）
private:
    int id_;
    double amt_;
    static int count_;
};

int Trade::next_id_ = 1000;                      // 在類別外「定義」並初始化（不再寫 static）
int Trade::count_ = 0;

int main() {
    Trade a(5e5), b(2e6);
    std::cout << "a.id = " << a.id() << "，b.id = " << b.id() << "\n";
    std::cout << "目前交易數 " << Trade::count() << "\n";   // 用「類別名::」存取
    {
        Trade c(1e6);
        std::cout << "區塊內 " << Trade::count() << "，c.id = " << c.id() << "\n";
    }
    std::cout << "區塊外 " << Trade::count() << "\n";
    Trade::next_id_ = 5000;                       // 透過類別修改，影響之後所有物件
    Trade d(1);
    std::cout << "d.id = " << d.id() << "\n";
    return 0;
}

區塊內 3，c.id = 1003

  • 類別內的 static int count_; 只是宣告；還必須在某一個 .cpp 的類別外定義一次：int Trade::count_ = 0;（不加 static），否則連結時會出現 undefined reference。
  • 存取方式：類別名::成員（建議）或 物件.成員。
  • static 成員變數存在靜態儲存區，程式開始就存在、結束才消失，和有沒有物件無關。
  • 常用於：物件計數、共用設定（如所有債券共用的計息慣例）、產生唯一編號。
  • 簡化寫法：static const int 或 static constexpr 成員可以直接在類別內初始化；C++17 起 inline static int count = 0; 也可以直接在類別內定義。
老師上課怎麼說老師怎麼講 static 成員變數
  • 不屬於物件，屬於類別：一般成員變數是「我有我的、你有你的」，兩個物件互不影響；加上 static 之後，同一張藍圖做出來的所有物件共用一份。所以要修改它，觀念上就應該「從它所歸屬的對象」來改——透過類別 MyClass::counter；用物件 obj.staticValue 也取得到，「只是碰巧從那個物件把它拿出來看」。

  • 存續期間：一般成員變數隨物件誕生、隨物件刪除；static 成員變數在程式一啟動就存在、程式結束才消失，放在靜態儲存區——既不是 heap（動態配置），也不是 stack。

7.6運算子重載

讓自訂型態也能用 ==、+、<<

內建型態可以直接 a == b、a + b，但對自訂類別，編譯器不知道「兩張債券怎樣算相等」「兩筆金額怎麼相加」。運算子重載（operator overloading）讓你替類別定義運算子的意義——本質上就是一個名字叫 operator運算子 的函數：

C++
#include <iostream>

class Money {
public:
    explicit Money(double v = 0) : value_(v) {}
    double value() const { return value_; }

    bool operator==(const Money &other) const { return value_ == other.value_; }   // a == b
    bool operator<(const Money &other) const { return value_ < other.value_; }     // a < b
    Money operator+(const Money &other) const { return Money(value_ + other.value_); }
    Money &operator+=(const Money &other) { value_ += other.value_; return *this; }
private:
    double value_;
};

// << 要寫成非成員函數：左邊是 std::ostream，不是 Money
std::ostream &operator<<(std::ostream &os, const Money &m) {
    return os << "NT$" << m.value();
}

int main() {
    Money a(100), b(250), c(100);
    std::cout << std::boolalpha << (a == c) << " " << (a == b) << " " << (a != b) << " " << (a < b) << "\n";
    Money total = a + b;                 // 呼叫 a.operator+(b)
    total += Money(50);
    std::cout << "合計 " << total << "\n";   // 呼叫 operator<<(std::cout, total)
    return 0;
}

  • C++20 起，定義了 == 後，!= 會自動可用；也可以寫 bool operator==(const Bond &) const = default; 讓編譯器逐一比較所有成員。
  • << 的左邊是 std::cout（std::ostream 型態），所以要寫成非成員函數，並回傳 ostream& 讓 << 可以串接。
  • 限制：只能重載 C++ 已有的運算子（不能發明新符號）；不能改變優先順序與運算元個數；::、.、?: 等不能重載；至少要有一個運算元是自訂型態。
  • 老師的提醒：重載要符合運算子原本的意義——== 就該判斷相等，不要拿來做加法或修改物件。
老師上課怎麼說不要自找麻煩

老師上課的說法：運算子重載時，「裡頭的實作行為是你定義的，所以不要自己找自己麻煩」——選了加號去重載，裡面做的卻像減法，沒有人會這樣做。C++20 可以用 = default 讓編譯器產生 ==，邏輯很簡單：逐一比較所有屬性是否相等。

  • 複製賦值：把一個物件的內容複製給另一個已經存在的物件——t5 = t1;。

老師上課強調一定要分清楚的四件事

老師上課特別強調：「什麼叫複製、什麼叫指派（賦值）、什麼叫複製建構、什麼叫建構，這一定要區分得非常清楚」。C++ 很重視程式的語意：同樣看起來有一個 =，Time t2 = t1; 是建構新物件（複製建構），t2 = t1; 是對已存在的物件賦值，會呼叫不同的函數、有不同的行為。

  • 沒有自己定義的話，編譯器會自動產生兩者，做法是逐一複製每個成員（memberwise copy）。對 int、double、string、vector 這類成員來說完全正確。

淺複製的危險與深複製

如果類別用裸指標擁有一塊動態記憶體，編譯器自動產生的「逐一複製成員」就會出事——它複製的是指標的值（位址），不是指標指向的資料，兩個物件會共用同一塊記憶體（淺複製）：

C++
#include <iostream>

class Series {                           // 錯誤示範：只有建構與解構，沒有處理複製
public:
    explicit Series(int n) : n_(n), data_(new double[n]()) {}
    ~Series() { delete[] data_; }
    double &at(int i) { return data_[i]; }
    double *raw() const { return data_; }
private:
    int n_;
    double *data_;
};

int main() {
    Series s1(3);
    s1.at(0) = 100;
    {
        Series s2 = s1;                  // 淺複製：s2.data_ 和 s1.data_ 是同一個位址
        std::cout << "s1.data_ = " << s1.raw() << "，s2.data_ = " << s2.raw() << "\n";
        s2.at(0) = 999;                  // 改 s2，s1 也被改了
        std::cout << "s1[0] = " << s1.at(0) << std::endl;
    }                                    // s2 解構：delete[] 了共用的記憶體
    std::cout << "s1 現在指向已釋放的記憶體……" << std::endl;
    return 0;                            // s1 解構時再 delete[] 一次：重複釋放

三個問題一次到齊：資料被意外共用、懸空指標、重複釋放（第 6 章）。解法是自己定義複製建構函數與複製賦值運算子做深複製——為新物件配置自己的記憶體，再把資料複製過去：

C++
#include <iostream>
#include <algorithm>

class Series {
public:
    explicit Series(int n) : n_(n), data_(new double[n]()) {}

    Series(const Series &other)                            // 複製建構函數：深複製
        : n_(other.n_), data_(new double[other.n_]) {
        std::copy(other.data_, other.data_ + n_, data_);
        std::cout << "  複製建構\n";
    }

    Series &operator=(const Series &other) {               // 複製賦值運算子：深複製
        if (this == &other) return *this;                  // 防止自我賦值 s = s
        double *fresh = new double[other.n_];
        std::copy(other.data_, other.data_ + other.n_, fresh);
        delete[] data_;                                    // 釋放舊資源
        data_ = fresh;
        n_ = other.n_;
        std::cout << "  複製賦值\n";
        return *this;                                      // 讓 a = b = c 可以串接
    }

    ~Series() { delete[] data_; }
    double &at(int i) { return data_[i]; }
private:
    int n_;
    double *data_;
};

int main() {
    Series s1(3);
    s1.at(0) = 100;
    Series s2 = s1;          // 複製建構
    s2.at(0) = 999;
    Series s3(5);
    s3 = s1;                 // 複製賦值
    s3 = s3;                 // 自我賦值：被 if 擋下
    std::cout << s1.at(0) << " " << s2.at(0) << " " << s3.at(0) << "\n";
    return 0;
}

  • 複製建構函數的形式：類別名(const 類別名 &other)；參數必須是參考（如果是傳值，傳值本身又要複製建構，會無限遞迴）。
  • 複製賦值運算子的形式：類別名 &operator=(const 類別名 &other)，最後 return *this;。
  • 自我賦值檢查 if (this == &other)：老師講義特別提到，如果沒有這一行，s = s 會先 delete 自己的資料、再從已刪除的記憶體複製。
重點三法則與零法則

三法則（rule of three）：如果一個類別需要自己寫解構函數、複製建構函數、複製賦值運算子其中任何一個，通常三個都需要。 零法則（rule of zero）：更好的做法是根本不要用裸指標擁有資源——成員改用 std::vector<double>、std::string、std::unique_ptr，它們自己會正確地複製（或禁止複製）與釋放，你一個特殊成員函數都不用寫。上面的 Series 只要把 double *data_ 換成 std::vector<double> data_，所有問題自動消失。

RAII：資源的一生綁在物件上

建構時取得資源、解構時釋放資源——這個 C++ 的核心慣用法叫 RAII（Resource Acquisition Is Initialization）。老師上課的例子是一個 FileHandler 類別：private 成員是一個 std::ofstream，建構函數開檔、解構函數關檔，兩者是對稱的操作；物件在 main 的大括號裡建立，程式離開大括號時物件被刪除，解構函數就自動把檔案關掉。老師也提醒：用 new 配置卻沒有在解構函數 delete 的話，你以為程式會幫你回收沒用到的記憶體，「但其實沒有」，可用的記憶體就會越來越少——記憶體洩漏。std::vector（記憶體）、std::ifstream（檔案）、std::unique_ptr（動態物件）都是 RAII：只要物件離開作用域，資源一定會被釋放，即使中途發生例外也一樣。這就是為什麼第 6 章的檔案不用手動 close、智慧指標不用手動 delete。

Q3

簡答｜難淺複製

一個類別用 int *data 指向 new 出來的記憶體，並在解構函數中 delete data，但沒有定義複製建構函數。說明 MyClass b = a; 之後會發生哪些問題。

答案

編譯器產生的複製建構函數逐一複製成員，b.data 得到的是 a.data 的位址（淺複製），兩個物件共用同一塊記憶體。問題有三：(1) 修改 b 指向的資料會同時改到 a；(2) 其中一個物件先解構時 delete 了這塊記憶體，另一個物件的指標變成懸空指標；(3) 另一個物件解構時又 delete 一次，造成重複釋放。解法是自己定義深複製的複製建構函數與複製賦值運算子，或改用 vector／智慧指標管理資源。

// Bond.cpp
#include "Bond.h"
#include <cmath>
#include <stdexcept>

int Bond::issued_ = 0;

Bond::Bond(const std::string &id, double face, double coupon, int years, int freq)
    : id_(id), face_(face), coupon_(coupon), years_(years), freq_(freq) {
    if (face <= 0 || years <= 0 || freq <= 0)
        throw std::invalid_argument("債券參數不合理");
    ++issued_;
}

std::vector<double> Bond::cashflows() const {
    int n = years_ * freq_;
    std::vector<double> cf(n, face_ * coupon_ / freq_);
    cf.back() += face_;
    return cf;
}

double Bond::price(double ytm) const {
    double p = 0, y = ytm / freq_;
    std::vector<double> cf = cashflows();
    for (std::size_t k = 0; k < cf.size(); ++k)
        p += cf[k] / std::pow(1 + y, k + 1);
    return p;
}

double Bond::ytm(double market_price) const {
    double lo = 0.0, hi = 1.0;
    while (hi - lo > 1e-12) {
        double mid = (lo + hi) / 2;
        if (price(mid) > market_price) lo = mid; else hi = mid;
    }
    return (lo + hi) / 2;
}

double Bond::macaulay_duration(double ytm) const {
    double y = ytm / freq_, weighted = 0;
    std::vector<double> cf = cashflows();
    for (std::size_t k = 0; k < cf.size(); ++k) {
        double t = static_cast<double>(k + 1) / freq_;          // 以「年」為單位的時間
        weighted += t * cf[k] / std::pow(1 + y, k + 1);
    }
    return weighted / price(ytm);
}

double Bond::modified_duration(double ytm) const {
    return macaulay_duration(ytm) / (1 + ytm / freq_);
}

std::ostream &operator<<(std::ostream &os, const Bond &b) {
    return os << "Bond(" << b.id() << ")";
}

寫程式｜難擴充 Bond

替上面的 Bond 加上 double convexity(double ytm) const（用數值近似：\(C \approx \dfrac{P(y-h) + P(y+h) - 2P(y)}{P(y)\,h^2}\)，取 \(h = 0.0001\)），並用「修正存續期間＋凸性」估計殖利率上升 100bp 時的價格變動百分比：\(\Delta P/P \approx -D_{mod}\,\Delta y + \tfrac12 C\,(\Delta y)^2\)。只需寫出新增的成員函數與 main 中的計算。

答案
C++
#include <iostream>
#include "Bond.h"

// 不修改 Bond.h 的前提下，先寫成一個使用 Bond 公開介面的普通函數
double convexity(const Bond &b, double y) {
    double h = 0.0001;
    double p = b.price(y);
    return (b.price(y - h) + b.price(y + h) - 2 * p) / (p * h * h);
}

int main() {
    Bond b("TW10Y", 100, 0.0175, 10);
    double y = 0.02, dy = 0.01;
    double D = b.modified_duration(y), C = convexity(b, y);
    double approx = -D * dy + 0.5 * C * dy * dy;
    double exact = b.price(y + dy) / b.price(y) - 1;
    std::cout << "D = " << D << "，C = " << C << "\n";
    std::cout << "近似變動 " << approx * 100 << "%，實際變動 " << exact * 100 << "%\n";
}

近似變動 -8.59261%，實際變動 -8.61047%

解析

因為 price 是 public 的 const 成員函數，不改類別也能寫出凸性；若要做成成員函數，就在 Bond.h 加宣告 double convexity(double ytm) const;，在 Bond.cpp 寫 double Bond::convexity(double y) const { ... }。「與類別相關但不需要存取 private」的功能寫成普通函數也是老師講義提到的做法。

7.9本章小結

  • 類別是自訂型態（藍圖），物件是實體；成員變數＋成員函數；. 與 -> 存取。
  • 封裝：public 是介面、private 是實作；class 預設 private、struct 預設 public。
  • 類別定義放 .h、成員函數實作放 .cpp，類別外實作要寫 類別名::。
  • 建構函數：與類別同名、無回傳型態、自動呼叫、可重載；寫了任何建構函數就沒有自動的預設建構函數；Time t(); 是函數宣告。
  • explicit 禁止單參數建構函數的隱式轉換；初始化列表 : a_(x), b_(y) {} 效率較好，const 與參考成員必須用它，初始化順序依宣告順序；類別內初始值；= default、= delete。
  • const 成員函數不修改物件，const 物件只能呼叫它；mutable 例外；this 指向目前物件，回傳 *this 可鏈式呼叫。
  • static 成員屬於類別：變數全體共用（類別外定義一次）、函數沒有 this，用 類別名:: 呼叫。
  • 運算子重載：operator==、operator<、operator+、非成員的 operator<<。
  • 複製建構 vs 複製賦值（目標是否已存在）；解構函數 ~類別名() 依建構的相反順序執行；裸指標成員要深複製（三法則），更好的是改用 vector／智慧指標（零法則）；RAII。
