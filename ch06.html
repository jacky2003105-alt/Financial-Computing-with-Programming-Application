6.1命名空間 namespace

為什麼需要命名空間

大型專案會用到很多程式庫，不同程式庫很可能都有叫 price、Option、log 的東西。命名空間（namespace）就是替名稱加上「姓氏」，讓同名的東西可以共存：

C++
#include <iostream>
#include <cmath>

namespace bond {
    double price(double face, double y, int n) {      // bond::price
        double p = 0;
        for (int t = 1; t <= n; ++t) p += face * 0.03 / std::pow(1 + y, t);
        return p + face / std::pow(1 + y, n);
    }
}

namespace equity {
    double price(double dividend, double r, double g) {   // equity::price（股利折現模型）
        return dividend / (r - g);
    }
}

int main() {
    std::cout << "債券價格 = " << bond::price(100, 0.035, 5) << "\n";
    std::cout << "股票價格 = " << equity::price(2.5, 0.08, 0.03) << "\n";
    return 0;
}

債券價格 = 97.7425
股票價格 = 50
  • 語法：namespace 名稱 { ... }（右大括號後不用分號）。
  • 用作用域運算子 :: 存取：命名空間::名稱。
  • 命名空間就是一個作用域；同一個命名空間可以分好幾段、寫在不同檔案，會合併在一起。
  • std 就是標準程式庫的命名空間，所以要寫 std::cout、std::vector。

同一個名字 price 在兩個命名空間中各有一個，彼此互不干擾。

using：少打一點字

C++
#include <iostream>
#include <vector>

namespace quant {
    double mean(const std::vector<double> &x) {
        double s = 0;
        for (double v : x) s += v;
        return s / x.size();
    }
}

int main() {
    using std::cout;                 // using 宣告：只引入 cout 一個名字
    cout << quant::mean({1, 2, 3}) << "\n";

    using namespace quant;           // using 指示：引入 quant 裡所有名字
    cout << mean({4, 5, 6}) << "\n";
    return 0;
}

2
5
  • using std::cout; 只引入一個名字；using namespace std; 引入全部。
  • 老師的提醒（也是業界共識）：不要在標頭檔裡寫 using namespace——所有 include 它的檔案都會被「污染」，名稱衝突的機率大增。在 .cpp 的函數裡局部使用則還好。本講義一律寫完整的 std::。

匿名命名空間與全域作用域 ::

C++
#include <iostream>

namespace {                          // 匿名命名空間：只有這個 .cpp 看得到
    int call_count = 0;
    void log_call() { ++call_count; }
}

int value = 100;                     // 全域變數

int main() {
    log_call(); log_call();
    std::cout << "call_count = " << call_count << "\n";

    int value = 50;                  // 區域變數遮住全域的 value
    std::cout << "區域 value = " << value << "，全域 value = " << ::value << "\n";
    return 0;
}

call_count = 2
區域 value = 50，全域 value = 100
  • 匿名命名空間（沒有名字的 namespace）裡的東西只在這個原始檔內有效，效果和第 5 章的 static 全域變數／函數一樣（內部連結），是現代 C++ 較建議的寫法。
  • ::名稱（前面什麼都不寫）代表全域作用域的名稱，可以在被遮住時取用全域變數。

Q2

簡答｜中using namespace

為什麼不建議在標頭檔中寫 using namespace std;？

答案

標頭檔會被許多 .cpp include，標頭檔中的 using namespace std 會把 std 的所有名稱帶進每一個 include 它的檔案的全域範圍，使用者無法拒絕。std 的名稱非常多（count、distance、data、size…），很容易和使用者自己的變數或函數撞名，造成難以理解的編譯錯誤或呼叫到錯誤的版本。

6.2前置處理器：#define、#include、條件編譯

編譯之前的「文字處理」

第 1 章提過建置流程：前置處理 → 編譯 → 組譯 → 連結。前置處理器只認得以 # 開頭的指令，它做的事情都是單純的文字替換，不懂 C++ 語法：

  • #define：巨集定義（文字替換）
  • #include：把另一個檔案的內容貼進來
  • #if／#ifdef／#ifndef：條件編譯（決定哪些程式碼要交給編譯器）

#define 與巨集的陷阱

C++
#include <iostream>

#define TRADING_DAYS 252              // 不帶參數的巨集：之後所有 TRADING_DAYS 換成 252
#define SQUARE_BAD(x) x * x           // 帶參數的巨集（危險寫法）
#define SQUARE(x) ((x) * (x))         // 正確寫法：參數與整體都加括號

int main() {
    std::cout << "一年交易日：" << TRADING_DAYS << "\n";
    std::cout << SQUARE_BAD(1 + 2) << "\n";     // 展開成 1 + 2 * 1 + 2 = 5
    std::cout << SQUARE(1 + 2) << "\n";         // 展開成 ((1 + 2) * (1 + 2)) = 9
    std::cout << "TRADING_DAYS 不會被替換\n";   // 字串裡的文字不會被替換
    return 0;
}

一年交易日：252
5
9
TRADING_DAYS 不會被替換
  • #define 名稱 內容：前置處理時把程式中的名稱換成內容（巨集展開）。習慣用全大寫命名。
  • 巨集不是語句，結尾不加分號；加了分號，分號也會被一起貼上：
C++
#define PI 3.1415926;

int main() {
    double y = PI * 2;      // 展開成 3.1415926; * 2;  → 語法錯誤
    return 0;
}

  • 帶參數的巨集只做文字替換、不計算、不檢查型態，所以老師強調參數要加括號。
  • 巨集從定義處有效到檔案結尾（或 #undef 名稱）。
重點能用 const／constexpr／inline 就不要用巨集

constexpr double PI = 3.1415926; 有型態、有作用域、編譯器能檢查；inline 函數或模板（第 9 章）可以取代帶參數的巨集。巨集在現代 C++ 主要只剩下 include guard 與條件編譯這兩個用途。

#include 與 include guard

  • #include <檔名>：到系統目錄找（標準程式庫）。
  • #include "檔名"：先在目前目錄找，找不到再去系統目錄（自己的標頭檔）。
  • #include 就是把那個檔案的內容原封不動貼進來；標頭檔可以再 include 其他標頭檔（巢狀）。

巢狀 include 很容易讓同一個標頭檔被貼進來兩次，造成重複定義。解法就是第 1 章看過的 include guard：

C++ 檔案：rates.h
// rates.h
#ifndef RATES_H          // 如果還沒定義 RATES_H……
#define RATES_H          // ……就定義它，並保留以下內容

struct Rate {
    double value;
    int days;
};

double annualize(const Rate &r);

#endif // RATES_H        // 第二次 include 時 RATES_H 已定義，整段被跳過
C++ 檔案：curve.h
// curve.h：也 include 了 rates.h
#ifndef CURVE_H
#define CURVE_H
#include "rates.h"

double discount(const Rate &r);

#endif
C++
#include <iostream>
#include "rates.h"
#include "curve.h"       // curve.h 又 include 一次 rates.h，但被 guard 擋掉了

double annualize(const Rate &r) { return r.value * 365.0 / r.days; }
double discount(const Rate &r) { return 1 / (1 + r.value); }

int main() {
    Rate r{0.01, 90};
    std::cout << "年化 " << annualize(r) << "，折現因子 " << discount(r) << "\n";
    return 0;
}

年化 0.0405556，折現因子 0.990099

把 rates.h 的 guard 拿掉，struct Rate 就會被定義兩次而編譯失敗。很多編譯器也支援更簡潔的 #pragma once（放在標頭檔第一行），效果相同。

條件編譯

C++
#include <iostream>

#define DEBUG                         // 開發時打開，正式版拿掉這行

int main() {
#ifdef _WIN32
    std::cout << "Windows\n";
#elif defined(__APPLE__)
    std::cout << "macOS\n";
#elif defined(__linux__)
    std::cout << "Linux\n";           // 依編譯平台只保留其中一段
#else
    std::cout << "其他平台\n";
#endif

    double pnl = 1234.5;
#ifdef DEBUG
    std::cout << "[DEBUG] pnl = " << pnl << "\n";   // 只在定義了 DEBUG 時才編譯進去
#endif
    std::cout << "完成\n";
    return 0;
}

Linux
[DEBUG] pnl = 1234.5
完成
指令 意義
#ifdef 名稱 … #endif 名稱有定義才編譯這段
#ifndef 名稱 … #endif 名稱沒定義才編譯這段（include guard）
#if 表達式 / #elif / #else 依常數表達式的值選擇

用途：跨平台程式（Windows／Mac／Linux 各寫一段）、開發時的除錯輸出、開關實驗性功能。也可以不改程式，直接在編譯指令加 -DDEBUG 來定義巨集。

預測輸出｜中巨集展開

下面程式印出什麼？

C++
#include <iostream>

Q2

選擇｜中include guard

include guard（#ifndef X_H / #define X_H / ... / #endif）的目的是？

  1. (A)讓標頭檔編譯得比較快
  2. (B)隱藏標頭檔中的變數與函數，讓其他檔案看不到
  3. (C)讓標頭檔只能被一個 .cpp 使用
  4. (D)避免同一個標頭檔在一個原始檔中被重複貼入
答案 (D)

避免同一個標頭檔在一個原始檔中被重複貼入

解析

第一次 include 時定義了 X_H，之後再被 include（例如透過其他標頭檔間接引入）時，#ifndef 不成立，整段內容被跳過，避免重複定義。

6.3記憶體的分區

老師把 C++ 程式使用的記憶體分成幾個區域：

區域 放什麼 誰管理 生命週期
堆疊（stack） 區域變數、形參、函數返回位址 編譯器自動 離開作用域就釋放
堆積（heap／free store） new 出來的物件 程式設計師 直到 delete
全域／靜態儲存區 全域變數、static 變數 編譯器 整個程式期間
常數儲存區 字串字面值等常數 編譯器 整個程式期間
C++
#include <iostream>

int g;                                   // 全域／靜態儲存區

int main() {
    int b = 1;                           // 堆疊
    static int d;                        // 全域／靜態儲存區
    const char *s = "TAIEX";             // s 在堆疊，"TAIEX" 在常數儲存區
    int *p = new int(42);                // p 在堆疊，p 指向的 int 在堆積
    std::cout << "堆疊   &b = " << &b << "\n";
    std::cout << "堆積    p = " << p << "\n";
    std::cout << "靜態   &g = " << &g << "，&d = " << &d << "\n";
    std::cout << "常數    s = " << static_cast<const void*>(s) << "\n";
    delete p;                            // 釋放堆積上的記憶體
    return 0;
}

堆疊   &b = 0x7ffc08699a24
堆積    p = 0x5560ed8012b0
靜態   &g = 0x5560b2d40154，&d = 0x5560b2d40158
常數    s = 0x5560b2d3e004

從位址可以看出它們位在完全不同的區段。

  • 堆疊：空間小（通常幾 MB）、配置極快、自動管理，但無法控制物件活多久。
  • 堆積：空間大（受實體記憶體限制）、配置較慢，物件的生命週期由你決定——也必須由你結束。

在函數裡宣告一個超大的陣列（例如 double a[10'000'000];，80 MB）會撐爆堆疊；std::vector<double> a(10'000'000); 則沒問題，因為 vector 會把元素放在堆積上。

6.4new 與 delete：手動管理堆積

配置與釋放

C++
#include <iostream>
#include <string>

int main() {
    int *p1 = new int;              // 配置一個 int，值不確定
    int *p2 = new int(3);           // 配置並初始化為 3
    int *p3 = new int();            // 值初始化為 0
    std::string *ps = new std::string(5, 'a');      // 配置並呼叫 string 的建構函數
    std::cout << *p2 << " " << *p3 << " " << *ps << "\n";

    int n = 5;                      // 實務上 n 來自輸入或檔案：執行時才知道
    double *prices = new double[n]; // 動態陣列：長度可以是變數！
    for (int i = 0; i < n; ++i) prices[i] = 100 + i * 0.5;
    std::cout << "最後一天 " << prices[n - 1] << "\n";

    delete p1;                      // 單一物件：delete
    delete p2;
    delete p3;
    delete ps;
    delete[] prices;                // 陣列：delete[]（不用寫長度）
    return 0;
}

3 0 aaaaa
最後一天 102
  • new 型態(初值) 在堆積上建立一個沒有名字的物件，回傳它的位址。
  • new 型態[n] 建立長度為 n 的陣列——和一般陣列不同，n 可以是執行時才知道的變數。
  • 用 new 建立類別物件時，會自動呼叫建構函數；delete 時會呼叫解構函數（第 7 章）。new／delete 比 C 語言的 malloc／free 多做了這兩件事。
  • new 和 delete 必須成對；new[] 配 delete[]，不能混用。

手動管理的三大問題

老師講義列出顯式記憶體管理最常見的錯誤：

1. 記憶體洩漏（memory leak）：忘了 delete。

C++
#include <iostream>

void simulate_path() {
    double *path = new double[252];     // 每次呼叫配置 2 KB
    path[0] = 100;
    // ……忘了 delete[] path;
}   // path 這個指標變數被銷毀了，但它指向的 2 KB 永遠沒人能釋放

int main() {
    for (int i = 0; i < 100000; ++i) simulate_path();     // 洩漏約 200 MB
    std::cout << "跑完了，但記憶體已經漏掉一大堆\n";
    return 0;
}

跑完了，但記憶體已經漏掉一大堆

指標變數（在堆疊上）離開作用域會被銷毀，但它指向的堆積物件不會自動釋放。短程式結束時作業系統會回收，但長時間運行的交易系統、風控服務會越吃越多記憶體，最後當掉。

2. 懸空指標（dangling pointer）：delete 之後還在用。

C++
#include <iostream>

int main() {
    int *p = new int(100);
    int *q = p;                // q 和 p 指向同一個物件
    delete p;                  // 物件被釋放
    p = nullptr;               // 好習慣：delete 後設為 nullptr
    std::cout << "q 還指著已經釋放的記憶體：*q 是未定義行為\n";
    // std::cout << *q;        // 千萬不要
    return 0;
}

q 還指著已經釋放的記憶體：*q 是未定義行為

3. 重複釋放（double free）：同一塊記憶體 delete 兩次。

C++
#include <iostream>

int main() {
    int *p = new int(7);
    int *q = p;
    delete p;
    std::cout << "第一次 delete 完成" << std::endl;
    delete q;                  // 重複釋放：程式通常會直接被終止
    std::cout << "不會印出" << std::endl;
    return 0;
}

第一次 delete 完成
free(): double free detected in tcache 2

（程式結束，回傳值 -6）

這三種錯誤在多人協作、多個指標指向同一物件、程式中途丟出例外時都很容易發生。C++11 的答案是智慧指標。

Q1

選擇｜易new 與 delete 配對

double *a = new double[100]; 應該用哪一行釋放？

  1. (A)delete a;
  2. (B)delete[] a;
  3. (C)free(a);
  4. (D)不需要釋放，函數結束會自動回收
答案 (B)delete[] a;

解析

new[] 必須配 delete[]；用 delete 釋放陣列是未定義行為；堆積上的記憶體不會因為指標離開作用域而自動釋放。

Q2

簡答｜中記憶體洩漏

在函數中寫 int *p = new int(5);，函數結束時沒有 delete。說明函數結束後「什麼被銷毀了」、「什麼沒有」。

答案

指標變數 p 本身是區域變數，存放在堆疊上，函數結束時被銷毀；但 p 指向的那個 int 是用 new 配置在堆積上的，不會自動釋放。由於已經沒有任何指標記得它的位址，這塊記憶體再也無法被 delete，造成記憶體洩漏。

6.5智慧指標：讓物件自己收拾

核心想法：擁有權

智慧指標（smart pointer）是把裸指標包起來的類別模板（在 <memory>）：當智慧指標離開作用域時，它會自動 delete 所指的物件。你不再需要手寫 delete，也就不會忘記。

C++ 標準程式庫的智慧指標：

智慧指標 擁有權 用途
std::unique_ptr<T> 獨占：同一時間只有一個指標擁有物件，可以轉移 預設首選
std::shared_ptr<T> 共享：多個指標共同擁有，最後一個消失時才釋放 物件需要被多方持有
std::weak_ptr<T> 不擁有：觀察 shared_ptr 管理的物件 打破循環參考
std::auto_ptr<T> （C++98，已被移除） 不要用

老師的原則：優先用 unique_ptr，不夠用時才用 shared_ptr。

unique_ptr：獨占

C++
#include <iostream>
#include <memory>
#include <vector>

struct Path {
    std::vector<double> s;
    Path(int n) : s(n, 100.0) { std::cout << "  建立 Path（" << n << " 天）\n"; }
    ~Path() { std::cout << "  釋放 Path\n"; }        // 解構函數：物件被銷毀時執行（第 7 章）
};

std::unique_ptr<Path> make_path(int n) {
    return std::make_unique<Path>(n);               // 建立並回傳：擁有權交給呼叫端
}

int main() {
    std::cout << "進入區塊\n";
    {
        std::unique_ptr<Path> p = std::make_unique<Path>(252);
        p->s[0] = 101;                              // 用法和普通指標一樣：-> 和 *
        std::cout << "  第一天 " << p->s[0] << "\n";
    }                                               // 離開區塊：自動釋放，不用 delete
    std::cout << "離開區塊\n";

    auto a = make_path(5);
    // auto b = a;                                  // 錯誤：unique_ptr 不能複製（獨占）
    auto b = std::move(a);                          // 可以「移交」擁有權
    std::cout << "a 現在是空的嗎？" << (a == nullptr) << "\n";
    std::cout << "程式結束前\n";
    return 0;
}

  • 用 std::make_unique<T>(建構參數) 建立（C++14）。
  • 不能複製，只能用 std::move 移交擁有權；移交後原本的指標變成空的。
  • 大小和裸指標一樣，幾乎沒有額外成本。

shared_ptr：共享與參考計數

C++
#include <iostream>
#include <memory>
#include <string>

int main() {
    auto p1 = std::make_shared<std::string>("USD/TWD 曲線");   // 參考計數 = 1
    std::cout << "use_count = " << p1.use_count() << "\n";
    {
        std::shared_ptr<std::string> p2 = p1;                  // 複製：計數 = 2
        auto p3(p1);                                           // 計數 = 3
        std::cout << "區塊內 use_count = " << p1.use_count() << "，內容：" << *p3 << "\n";
    }                                                          // p2、p3 銷毀：計數回到 1
    std::cout << "區塊外 use_count = " << p1.use_count() << "\n";

    p1.reset();                                                // 放棄擁有：計數歸 0 → 物件被釋放
    std::cout << "reset 後 p1 是空的：" << std::boolalpha << (p1 == nullptr) << "\n";

    auto p4 = std::make_shared<int>(100);
    p4 = std::make_shared<int>(400);                           // 指向新物件，舊的 100 自動釋放
    std::cout << *p4 << "\n";
    return 0;
}

use_count = 1
區塊內 use_count = 3，內容：USD/TWD 曲線
區塊外 use_count = 1

400
  • 每個 shared_ptr 物件都會記錄「有幾個 shared_ptr 指向同一物件」——參考計數（reference count），用 use_count() 查看。
  • 複製 shared_ptr 讓計數 +1；一個 shared_ptr 被銷毀或 reset() 讓計數 −1；計數歸零時自動 delete 物件。概念類似 R、Python 的垃圾回收。
  • 用 std::make_shared<T>(參數) 建立：只配置一次記憶體（物件和計數放在一起），比 std::shared_ptr<T>(new T(...)) 有效率，也避免裸指標外流。
  • 智慧指標的建構函數是 explicit，不能寫 std::shared_ptr<int> p = new int(1);。
金融應用共享的市場資料

多個商品（債券、利率交換、選擇權）都要用同一條殖利率曲線來折現。讓每個商品持有一個指向曲線的 shared_ptr：曲線只有一份，大家共用；最後一個商品也被銷毀時，曲線才自動釋放。QuantLib 這類量化程式庫大量使用這種設計（第 10 章會看到 Handle 與觀察者模式）。

不要混用裸指標與智慧指標

C++
#include <iostream>
#include <memory>

int main() {
    int *raw = new int(5);
    std::shared_ptr<int> a(raw);
    // std::shared_ptr<int> b(raw);  // 千萬不要：兩個「各自計數」的 shared_ptr 會 delete 同一個物件兩次
    std::shared_ptr<int> b = a;      // 正確：從既有的 shared_ptr 複製，共用同一個計數
    std::cout << a.use_count() << "\n";

    int *peek = a.get();             // get()：暫時取得裸指標（例如呼叫舊的 C 函數）
    std::cout << *peek << "\n";      // 只能看，不要 delete 它
    return 0;
}

2
5

規則：一律用 make_unique／make_shared 建立，不要自己 new 再交給智慧指標；需要裸指標時只用 get() 短暫存取，絕不 delete。

weak_ptr（認識即可）

std::weak_ptr 指向 shared_ptr 管理的物件，但不增加參考計數，用來「觀察」物件是否還活著（lock() 會回傳一個 shared_ptr，物件已消失時回傳空的）。主要用來打破兩個物件互相持有 shared_ptr、計數永遠不會歸零的循環參考。

Q1

選擇｜中智慧指標選擇

一個模擬函數要建立一大塊路徑資料並交給呼叫端，資料只會有一個擁有者。最適合的回傳型態是？

  1. (A)double*
  2. (B)std::weak_ptr<Paths>
  3. (C)std::shared_ptr<Paths>
  4. (D)std::unique_ptr<Paths>
答案 (D)std::unique_ptr<Paths>

解析

單一擁有者用 unique_ptr，回傳時擁有權直接移交給呼叫端，離開作用域自動釋放。裸指標要靠呼叫端記得 delete；shared_ptr 有不必要的計數成本；weak_ptr 不擁有物件。

Q2

預測輸出｜中參考計數

下面程式印出什麼？

C++
#include <iostream>
#include <memory>
int main() {
    auto a = std::make_shared<double>(1.5);
    auto b = a;
    std::shared_ptr<double> c;
    c = b;
    std::cout << a.use_count() << " ";
    b.reset();
    std::cout << a.use_count() << " " << *c << "\n";
}
答案
3 2 1.5

解析

a、b、c 共用同一物件，計數 3；b.reset() 後剩 a、c，計數 2，物件仍存在。

Q3

找錯｜難重複擁有

下面程式有什麼問題？

C++
double *raw = new double(0.02);
std::shared_ptr<double> r1(raw);
std::shared_ptr<double> r2(raw);
答案

r1 和 r2 都從同一個裸指標建立，各自擁有一個獨立的參考計數，彼此不知道對方存在。當兩者都離開作用域時，會各 delete 一次同一塊記憶體（重複釋放），屬於未定義行為。應該寫成 auto r1 = std::make_shared<double>(0.02); auto r2 = r1;，讓它們共用同一個計數。

6.6補充：讀寫檔案

換個角度想講義外的補充

這一節老師的講義沒有，但金融程式幾乎都要從檔案讀資料（價格、交易紀錄）、把結果寫出去，所以補充最基本的用法。

C++ 用 <fstream> 讀寫檔案，用法和 cin／cout 幾乎一樣：std::ofstream（output file stream）寫檔，std::ifstream 讀檔；<sstream> 的 std::stringstream 則可以把一個字串當成資料流來切割。

C++
#include <iostream>
#include <fstream>
#include <sstream>
#include <string>
#include <vector>

struct Bar {
    std::string date;
    double close;
    long long volume;
};

int main() {
    // 1. 寫檔：先產生一個 CSV（實務上這個檔案來自資料商或 R 匯出）
    {
        std::ofstream out("prices.csv");
        out << "date,close,volume\n";
        out << "2026-11-09,1005.0,32100\n";
        out << "2026-11-10,1012.5,28750\n";
        out << "2026-11-11,998.0,41230\n";
        out << "2026-11-12,1015.0,35020\n";
    }   // out 離開作用域時自動關閉檔案

    // 2. 讀檔：一列一列讀，再用 stringstream 以逗號切開
    std::ifstream in("prices.csv");
    if (!in) {                                      // 檔案打不開時要處理
        std::cerr << "找不到檔案\n";
        return 1;
    }
    std::string line;
    std::getline(in, line);                         // 跳過標題列
    std::vector<Bar> bars;
    while (std::getline(in, line)) {                // 讀到檔尾時 getline 回傳 false
        std::stringstream ss(line);
        std::string date, close, vol;
        std::getline(ss, date, ',');                // 第三個參數：分隔字元
        std::getline(ss, close, ',');
        std::getline(ss, vol, ',');
        bars.push_back({date, std::stod(close), std::stoll(vol)});
    }

    // 3. 計算並寫出結果
    std::ofstream res("returns.txt");
    for (std::size_t t = 1; t < bars.size(); ++t) {
        double r = bars[t].close / bars[t - 1].close - 1;
        res << bars[t].date << " " << r << "\n";
        std::cout << bars[t].date << " 報酬 " << r * 100 << "%，成交量 " << bars[t].volume << "\n";
    }
    std::cout << "共讀入 " << bars.size() << " 筆，結果已寫入 returns.txt\n";
    return 0;
}

2026-11-10 報酬 0.746269%，成交量 28750
2026-11-11 報酬 -1.4321%，成交量 41230
2026-11-12 報酬 1.70341%，成交量 35020
共讀入 4 筆，結果已寫入 returns.txt
  • std::ofstream out("檔名"); 開檔寫入，之後 out << ... 就像 cout。
  • std::ifstream in("檔名"); 開檔讀取；if (!in) 檢查是否成功開啟。
  • while (std::getline(in, line)) 是「讀到檔尾為止」的標準寫法。
  • std::getline(ss, 欄位, ',') 以逗號為分隔讀取一個欄位。
  • 檔案物件離開作用域時會自動關閉——這和智慧指標自動釋放記憶體是同一個想法（RAII：資源的生命週期綁在物件上），第 7 章學 class 時會正式介紹。

Q1

寫程式｜中讀檔計算平均

修改上面的程式：讀入 prices.csv 後，計算平均收盤價與最大成交量，印出來。（先寫檔再讀檔，讓程式可以獨立執行。）

答案
C++
#include <iostream>
#include <fstream>
#include <sstream>
#include <string>

int main() {
    {
        std::ofstream out("prices.csv");
        out << "date,close,volume\n2026-11-09,1005.0,32100\n2026-11-10,1012.5,28750\n"
            << "2026-11-11,998.0,41230\n2026-11-12,1015.0,35020\n";
    }
    std::ifstream in("prices.csv");
    std::string line;
    std::getline(in, line);
    double sum = 0;
    long long max_vol = 0;
    int n = 0;
    while (std::getline(in, line)) {
        std::stringstream ss(line);
        std::string d, c, v;
        std::getline(ss, d, ',');
        std::getline(ss, c, ',');
        std::getline(ss, v, ',');
        sum += std::stod(c);
        long long vol = std::stoll(v);
        if (vol > max_vol) max_vol = vol;
        ++n;
    }
    std::cout << "平均收盤 " << sum / n << "，最大成交量 " << max_vol << "\n";
}

平均收盤 1007.62，最大成交量 41230

6.7本章小結

  • 命名空間：namespace 名 { } 避免名稱衝突，:: 存取；using 宣告／指示（不要放在標頭檔）；匿名命名空間限本檔使用；::名稱 取全域。
  • 前置處理器做文字替換：#define（巨集，注意括號與分號，能用 constexpr／inline 就不用巨集）、#include（<> 系統、"" 自己的）、include guard、#ifdef／#if 條件編譯。
  • 記憶體分區：堆疊（自動）、堆積（new／delete 手動）、靜態儲存區、常數儲存區。
  • new／delete 要成對（new[] 配 delete[]）；三大錯誤：記憶體洩漏、懸空指標、重複釋放。
  • 智慧指標（<memory>）：unique_ptr 獨占（首選，make_unique、std::move 移交）、shared_ptr 共享（參考計數 use_count、make_shared、reset）、weak_ptr 觀察；不要和裸指標混用。
  • 檔案：ofstream 寫、ifstream 讀、getline 逐列、stringstream 切欄位。
