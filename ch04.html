4.1表達式、運算子與優先順序

名詞

  • 表達式（expression）：會產生一個結果的計算，例如 3 + 2、price * shares、"Hello"。
  • 運算元（operand）：參與運算的對象（3 和 2）；運算子（operator）：運算的符號（+）。
  • 依運算元個數分為一元（-x、!ok、*p、&x）、二元（a + b、a == b）、三元（只有一個：? :）。同一個符號可能有不同角色：* 在 *p 是解參考，在 a * b 是乘法。
  • 表達式後面加上分號 ; 就變成語句（statement）。

優先順序與結合律

C++
#include <iostream>

int main() {
    double salary = 50000, bonus = 8000, penalty = 1000;
    std::cout << 1.2 * (salary + bonus - penalty) << "\n";   // 括號先算
    std::cout << 2 + 3 * 4 << "  " << (2 + 3) * 4 << "\n";   // 先乘除後加減
    std::cout << 100 / 10 / 2 << "\n";                       // 左結合：(100 / 10) / 2 = 5
    std::cout << 2 - 3 - 4 << "\n";                          // (2 - 3) - 4 = -5
    return 0;
}

68400
14  20
5
-5
  • 優先順序（precedence）決定誰先算：乘除 * / % 高於加減 + -。
  • 優先順序相同時看結合律（associativity）：算術運算子是左結合（由左往右），賦值 = 是右結合。
  • 大致順序（高 → 低）：一元運算子（!、-x、++、*p）→ 乘除餘 → 加減 → 比較 < <= > >= → 相等 == != → && → || → ?: → 賦值 = += → 逗點 ,。
  • 老師的建議：記不清楚就加括號，可讀性也比較好。

左值與右值（複習與延伸）

第 2 章提過：左值是有位址、可以放在 = 左邊的東西（變數、*p、v[i]）；右值是臨時的結果（3、a + b、i++ 的結果）。

C++
int main() {
    int i = 0, k = 0;
    const int ci = i;
    1024 = k;        // 錯誤：字面值是右值
    i + k = k;       // 錯誤：算術結果是右值
    ci = k;          // 錯誤：ci 是左值，但是 const，不能修改
    return 0;
}

老師講義列出各運算子對左右值的要求，重點是：= 左邊要可修改的左值；&x 要左值、結果是右值（一個指標值）；*p、v[i]、*it 的結果是左值（所以可以 *p = 5;）；++i 回傳左值、i++ 回傳右值。

Q1

預測輸出｜易優先順序

下面程式印出什麼？

C++
#include <iostream>
int main() {
    std::cout << 10 - 4 / 2 * 3 << " " << (10 - 4) / 2 * 3 << " " << 20 % 6 * 2 << "\n";
}
答案
4 9 4

解析

4 / 2 * 3 由左往右 = 6，10 − 6 = 4；(10 − 4) / 2 * 3 = 9；20 % 6 = 2，再乘 2 = 4。

隱式轉換：自動統一型態

二元運算子需要兩邊型態相同，不同時編譯器會自動轉換（隱式轉換），原則是往能表達較大範圍的型態轉，盡量不損失精度：

C++
#include <iostream>
#include <typeinfo>

int main() {
    float a = 2.2f, b = 3.5f;
    char c1 = 2, c2 = 3;
    short s1 = 1, s2 = 6;
    long n = 15;
    auto r1 = a + 12.4;     // float + double → double
    auto r2 = a + b;        // float + float  → float
    auto r3 = c1 + c2;      // char + char    → int（小整數一律先升成 int）
    auto r4 = s1 + s2;      // short + short  → int
    auto r5 = n + a;        // long + float   → float
    std::cout << sizeof(r1) << " " << sizeof(r2) << " " << sizeof(r3) << " "
              << sizeof(r4) << " " << sizeof(r5) << "\n";
    std::cout << typeid(r1).name() << " " << typeid(r3).name() << "\n";   // d = double, i = int
    return 0;
}

8 4 4 4 4
d i
  • char、short、bool 參與運算時會先提升成 int（整數提升）。
  • 有一邊是 unsigned、另一邊是有號整數時，有號的會被轉成 unsigned——第 2 章 i - u 變成超大數的原因。
  • 初始化或賦值時，右邊會被轉成左邊變數的型態（int k = 3.14; 得到 3）。
  • 條件判斷中，非 bool 值會轉成 bool（0 為 false）。

老師講義的有趣例子：對 bool 取負號

C++
#include <iostream>

int main() {
    bool b = true;
    bool b2 = -b;       // true 先提升為 int 1，取負得 -1，再轉回 bool：非 0 → true！
    std::cout << std::boolalpha << b2 << "\n";
    return 0;
}

true

教訓：不要對 bool 做算術。

顯式轉換：static_cast 與其他

需要自己決定轉型時（顯式轉換、強制轉型），C++ 提供四種具名的轉型：

C++
#include <iostream>

int main() {
    double f = 100.723;
    int i1 = (int)f;                       // C 風格：能用，但不檢查、也不容易搜尋
    int i2 = static_cast<int>(f);          // C++ 風格：建議
    std::cout << i1 << " " << i2 << "\n";

    int wins = 7, games = 9;
    double rate = static_cast<double>(wins) / games;   // 避免整數除法
    std::cout << "勝率 " << rate << "\n";

    int k = 5 % static_cast<int>(3.2);     // % 需要整數
    std::cout << k << "\n";
    return 0;
}

100 100
勝率 0.777778
2
轉型 用途
static_cast<T>(x) 一般轉型（數值之間、void* 轉回原型態、子類別轉父類別），編譯期檢查。最常用
dynamic_cast<T>(x) 執行期檢查的轉型，用於父類別指標轉子類別（第 8 章繼承）
const_cast<T>(x) 去掉 const 屬性；修改原本是 const 的物件是未定義行為，避免使用
reinterpret_cast<T>(x) 把位元直接當另一種型態解讀，非常危險，避免使用

static_cast 不能做「不相關的指標」之間的轉換：

C++
int main() {
    double f = 100.0;
    double *pf = &f;
    int *pi = static_cast<int*>(pf);    // 錯誤：double* 與 int* 無關，static_cast 拒絕
    return 0;
}

      |               ^~~~~~~~~~~~~~~~~~~~~

老師的態度：強制轉型會壓掉編譯器的檢查，能不用就不用；要用就用 C++ 風格，讓意圖清楚、也容易搜尋。

預測輸出｜中整數除法與轉型

C++
#include <iostream>
int main() {
    int up = 13, total = 20;

4.3比較與邏輯運算

關係運算子與邏輯運算子

運算子 意義
<、<=、>、>= 大小比較
==、!= 相等、不相等（注意 == 是兩個等號）
! 邏輯「非」
&& 邏輯「且」：兩邊都 true 才 true
\|\| 邏輯「或」：任一邊 true 就 true

結果都是 bool。

C++
#include <iostream>

int main() {
    double pe = 14.5, roe = 0.18, debt_ratio = 0.65;
    bool cheap = pe < 15;
    bool quality = roe >= 0.15 && debt_ratio < 0.6;
    bool pick = cheap && (quality || roe > 0.2);
    std::cout << std::boolalpha << cheap << " " << quality << " " << pick << " " << !cheap << "\n";
    return 0;
}

true false false false

短路求值

&& 和 || 先算左邊，如果左邊已經能決定結果，右邊就不算了：

  • A && B：A 是 false 時，結果一定 false，不算 B。
  • A || B：A 是 true 時，結果一定 true，不算 B。

這可以拿來做「安全檢查」：

C++
#include <iostream>
#include <vector>

int main() {
    std::vector<double> prices;           // 空的
    // 先檢查不是空的，才去讀 prices[0]；如果反過來寫，會讀到不存在的元素
    if (!prices.empty() && prices[0] > 100) {
        std::cout << "開盤價超過 100\n";
    } else {
        std::cout << "沒有資料或沒超過\n";
    }

    int shares = 0;
    double cost = 5000;
    if (shares != 0 && cost / shares > 50) {   // shares 為 0 時不會去做除法
        std::cout << "均價高於 50\n";
    }
    return 0;
}

沒有資料或沒超過

兩個常見陷阱

C++
#include <iostream>

int main() {
    int i = 5, j = 3, k = 2;
    if (i < j < k) {                     // 被解讀為 (i < j) < k → false < 2 → 0 < 2 → true！
        std::cout << "i < j < k ？這不對吧\n";
    }
    if (i < j && j < k) {                // 正確寫法
        std::cout << "不會印出\n";
    }

    double rate = 0.05;
    if (rate = 0) {                      // 把 == 打成 =：這是「賦值」，rate 被改成 0，條件為 false
        std::cout << "不會印出\n";
    }
    std::cout << "rate 被改成 " << rate << " 了\n";
    return 0;
}

  • 數學的 \(i < j < k\) 在 C++ 要寫成 i < j && j < k。

Concept Check：4.3 比較與邏輯運算

自編練習題（選擇、填空、預測輸出、找錯、寫程式），不是老師出的題目。寫程式題的參考答案都實際編譯執行過。

Q1

選擇｜中短路求值

int n = 0; 執行 bool ok = (n > 0) && (100 / n > 5); 會發生什麼？

  1. (A)先算 100 / n，除以 0 讓程式崩潰
  2. (B)編譯錯誤，因為不能在 if 的條件裡面做除法
  3. (C)ok 為 true，因為右邊條件成立
  4. (D)ok 為 false，且右邊不會被計算
答案 (D)

ok 為 false，且右邊不會被計算

解析

&& 左邊 n > 0 為 false，結果已確定為 false，右邊不會被計算，所以不會除以 0。

Q2

預測輸出｜中連續比較

下面程式印出什麼？

C++
#include <iostream>
int main() {
    int a = 9, b = 5, c = 7;
    std::cout << (a > b > c) << " " << (a > b && b > c) << "\n";
}
答案
0 0

解析

a > b > c 解讀為 (a > b) > c，即 1 > 7，為 false（印 0）；a > b && b > c 中 b > c 為 false，結果也是 0。換成 c = 0 時兩者就會不同。

Q3

寫程式｜中選股條件

一檔股票滿足「本益比介於 8 到 20（含）之間，而且（殖利率 ≥ 4% 或 ROE ≥ 15%）」就列入觀察。寫程式判斷本益比 12、殖利率 3.5%、ROE 17% 的股票是否列入，印出 true/false。

答案
C++
#include <iostream>

int main() {
    double pe = 12, dy = 0.035, roe = 0.17;
    bool watch = (pe >= 8 && pe <= 20) && (dy >= 0.04 || roe >= 0.15);
    std::cout << std::boolalpha << watch << "\n";
}

true

解析

「介於」要拆成兩個比較用 && 連接；「或」的部分要加括號，因為 && 的優先順序比 || 高。

4.4賦值、遞增與其他運算子

賦值運算子

C++
#include <iostream>

int main() {
    int a, b, c;
    a = b = c = 0;            // 右結合：a = (b = (c = 0))
    double nav = 10.0;
    nav += 0.25;              // 等於 nav = nav + 0.25
    nav *= 1.02;              // 等於 nav = nav * 1.02
    int days = 100;
    days /= 3;                // 整數：33
    days %= 7;                // 33 % 7 = 5
    std::cout << a << b << c << " " << nav << " " << days << "\n";
    int k;
    k = 3.99;                 // 賦值時轉成左邊型態：3
    std::cout << k << "\n";
    return 0;
}

000 10.455 5
3
  • 賦值的結果就是左邊的那個變數（左值），所以可以串接 a = b = 0。
  • 複合賦值：+=、-=、*=、/=、%=。
  • 賦值的優先順序很低，在條件裡使用時要加括號：while ((x = next()) != 42)。
  • k = {3.14}; 用大括號賦值同樣禁止縮窄轉換。

遞增與遞減：前置 vs 後置

C++
#include <iostream>

int main() {
    int i = 0, j;
    j = ++i;      // 前置：先加 1，再把「加完的 i」交出去
    std::cout << "j = ++i → i = " << i << "，j = " << j << "\n";

    i = 0;
    j = i++;      // 後置：先把「原本的值」複製一份交出去，再把 i 加 1
    std::cout << "j = i++ → i = " << i << "，j = " << j << "\n";
    return 0;
}

j = ++i → i = 1，j = 1
j = i++ → i = 1，j = 0
  • 前置 ++i：加 1 後回傳 i 本身（左值）。
  • 後置 i++：回傳原值的副本（右值），再加 1。
  • 老師的建議：不需要原值時，一律用前置 ++i——後置版本要多存一份副本，對迭代器這種物件會比較慢。所以本講義的迴圈都寫 ++i 或 ++it。

*p++ 是常見寫法：++ 優先順序比 * 高，所以是 *(p++)：先取得 p 原本指的元素，p 再往後移。

C++
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {5, 8, 3, -1, 7};
    auto it = v.begin();
    while (it != v.end() && *it >= 0) {      // 印到第一個負數為止
        std::cout << *it++ << " ";           // 印出目前元素，然後 it 往後移
    }
    std::cout << "\n";
    return 0;
}

5 8 3

不要在同一個表達式裡又改又讀同一個變數，例如 *it = toupper(*it++); 或 i = i++ + 1;——求值順序沒有規定，結果是未定義行為。

成員存取、條件運算子、逗點運算子

C++
#include <iostream>
#include <string>

int main() {
    std::string s = "a string", *p = &s;
    std::cout << s.size() << " " << (*p).size() << " " << p->size() << "\n";   // 三者相同
    // *p.size() 是錯的：. 的優先順序比 * 高，會變成 *(p.size())

    double a = 3.2, b = 4.7;
    double mx = (a > b) ? a : b;                   // 條件 ? 為真時的值 : 為假時的值
    double pnl = -1250;
    std::cout << "較大者 " << mx << "，" << (pnl >= 0 ? "獲利" : "虧損") << "\n";

    int x, y;
    x = (y = 3, y * 6);                            // 逗點：由左往右算，結果是最右邊的值
    std::cout << "y = " << y << "，x = " << x << "\n";
    return 0;
}

8 8 8
較大者 4.7，虧損
y = 3，x = 18
  • . 用於物件，-> 用於指標（等於 (*p).）。
  • 條件運算子 cond ? e1 : e2 是唯一的三元運算子，適合「二選一」的簡短判斷；巢狀太多層會很難讀，那時改用 if。
  • 逗點運算子優先順序最低；最常見的合理用途是在 for 的第三段同時更新兩個變數：for (i = 0, j = n - 1; i < j; ++i, --j)。

4.6條件語句：if 與 switch

if / else if / else

C++
#include <iostream>

int main() {
    double scores[] = {92, 78, 55, 85, 64};
    for (double s : scores) {
        char grade;
        if (s >= 90) {
            grade = 'A';
        } else if (s >= 80) {          // 前面不成立才會檢查這裡
            grade = 'B';
        } else if (s >= 70) {
            grade = 'C';
        } else if (s >= 60) {
            grade = 'D';
        } else {
            grade = 'F';
        }
        std::cout << s << " → " << grade << "\n";
    }
    return 0;
}

92 → A
78 → C
55 → F
85 → B
64 → D
  • 條件一定要用 () 括起來；結果要能轉成 bool。
  • 由上往下檢查，第一個成立的就執行，後面的不看了，所以條件的順序很重要。
  • 本體只有一行時可以省略 { }，但老師的例子顯示這很容易出錯：

懸空的 else

C++
#include <iostream>

int main() {
    int grade = 92;              // 個位數是 2
    char tag = ' ';
    if (grade % 10 >= 3)
        if (grade % 10 > 7)
            tag = '+';
    else                          // 看起來屬於外層 if，其實屬於「最近的、還沒配對的」內層 if
        tag = '-';
    std::cout << "[" << tag << "]\n";    // 期待 '-'，結果是空白
    return 0;
}

[ ]

C++ 規定：else 和離它最近、還沒配對的 if 配成一組，縮排完全不影響。要讓 else 屬於外層 if，就用大括號：

C++
#include <iostream>

int main() {
    int grade = 92;
    char tag = ' ';
    if (grade % 10 >= 3) {
        if (grade % 10 > 7)
            tag = '+';
    } else {
        tag = '-';
    }
    std::cout << "[" << tag << "]\n";
    return 0;
}

[-]
重點永遠寫大括號

即使 if、for、while 的本體只有一行，也養成寫 { } 的習慣。可以避免懸空 else，也避免日後多加一行時忘了補括號。

switch：依整數值分派

C++
#include <iostream>

enum class OrderType { Market, Limit, Stop, StopLimit };

int main() {
    OrderType types[] = {OrderType::Limit, OrderType::Stop, OrderType::Market};
    for (OrderType t : types) {
        switch (t) {
        case OrderType::Market:
            std::cout << "市價單：立即以市場價格成交\n";
            break;                         // 沒有 break 會繼續往下執行！
        case OrderType::Limit:
            std::cout << "限價單：價格達到才成交\n";
            break;
        case OrderType::Stop:
        case OrderType::StopLimit:         // 兩個 case 共用同一段處理
            std::cout << "停損類委託：觸價後送出\n";
            break;
        default:
            std::cout << "未知的委託類型\n";
        }
    }
    return 0;
}

限價單：價格達到才成交
停損類委託：觸價後送出
市價單：立即以市場價格成交
  • switch (表達式) 的值必須是整數、字元或 enum（不能是 double、string）。
  • 每個 case 後面是不重複的常數。
  • 匹配到某個 case 後，會從那裡一路往下執行，直到遇到 break 或 switch 結尾——這叫 fall through。要停就寫 break。
  • 故意不寫 break（多個 case 共用處理）時，老師建議加註解說明。
  • default 處理所有沒列到的情況。

忘了 break 的後果：

C++

    int score = 0;
    switch (rating) {
    case 'A': score += 3;      // 忘了 break
    case 'B': score += 2;      // 忘了 break
    case 'C': score += 1;
    }

for

C++
#include <iostream>
#include <iomanip>
#include <cmath>

int main() {
    std::cout << std::fixed << std::setprecision(0);
    // 每月定期定額 5000，年報酬 6%（月複利），20 年後
    double monthly = 5000, r = 0.06 / 12, value = 0;
    for (int m = 1; m <= 240; ++m) {

            std::cout << "第 " << m / 12 << " 年：" << value << "\n";

第 10 年：819397
第 15 年：1454094

for (表達式1; 表達式2; 表達式3) 本體：

  1. 表達式1（初始化）只執行一次；
  2. 檢查表達式2（條件），為 true 就執行本體，為 false 就結束；
  3. 執行表達式3（更新），回到第 2 步。

三個部分都可以省略（但分號不能省）：for (;;) 和 while (true) 都是「無窮迴圈」，要靠 break 跳出。老師講義用 1 加到 100 示範了各種省略寫法，結果都是 5050：

C++
#include <iostream>

int main() {
    int sum = 0, i = 1;
    for (;;) {                  // 三個都省略
        sum += i;
        if (i >= 100) break;
        ++i;
    }
    std::cout << "sum = " << sum << "\n";
    return 0;
}

sum = 5050

range for 走過容器的每個元素
while 不知道要跑幾次，直到某條件達成（收斂、讀到檔尾）
do-while 至少要做一次（輸入驗證）

房貸 800 萬、年利率 2.1%（月利率 = 年利率 / 12）、20 年按月本息平均攤還。每月付款 \(PMT = P \cdot \dfrac{r}{1-(1+r)^{-n}}\)。用 for 迴圈模擬攤還，印出每月付款、第 1 期的利息與本金，以及每 5 年底的剩餘本金。

答案
C++
#include <iostream>
#include <iomanip>
#include <cmath>

int main() {
    double P = 8000000, r = 0.021 / 12;
    int n = 240;
    double pmt = P * r / (1 - std::pow(1 + r, -n));
    std::cout << std::fixed << std::setprecision(0);
    std::cout << "每月付款：" << pmt << "\n";
    double balance = P;
    for (int m = 1; m <= n; ++m) {
        double interest = balance * r;
        double principal = pmt - interest;
        balance -= principal;
        if (m == 1) {
            std::cout << "第 1 期 利息 " << interest << "，本金 " << principal << "\n";
        }
        if (m % 60 == 0) {
            std::cout << "第 " << m / 12 << " 年底剩餘本金：" << std::abs(balance) << "\n";
        }
    }
}

第 15 年底剩餘本金：2324818
第 20 年底剩餘本金：0

解析

每期利息 = 剩餘本金 × 月利率，本金 = 付款 − 利息。最後剩餘本金應為 0（浮點誤差可能出現 −0，所以用 abs）。

    std::vector<double> daily = {0.012, -0.004, 0.008, -0.021, -0.035, 0.015, 0.006};
    double value = 1.0, peak = 1.0;
    for (std::size_t t = 0; t < daily.size(); ++t) {
        if (daily[t] > 0.01) {
            std::cout << "第 " << t + 1 << " 天大漲，跳過不記錄\n";
            continue;                          // 跳過本次剩下的部分，直接進入下一次
        }
        value *= 1 + daily[t];
        if (value > peak) peak = value;
        double dd = value / peak - 1;          // 從高點回落的幅度
        std::cout << "第 " << t + 1 << " 天 淨值 " << value << " 回撤 " << dd << "\n";
        if (dd < -0.05) {
            std::cout << "回撤超過 5%，觸發停損！\n";
            break;                             // 直接結束整個迴圈
        }
    }
    return 0;
}

第 1 天大漲，跳過不記錄
第 2 天 淨值 0.996 回撤 -0.004
第 3 天 淨值 1.00397 回撤 0
第 4 天 淨值 0.982885 回撤 -0.021
第 5 天 淨值 0.948484 回撤 -0.055265
回撤超過 5%，觸發停損！
  • break：立刻結束最內層的迴圈（或 switch），從迴圈後面的第一行繼續。
  • continue：結束這一次，直接進入下一次（for 會先執行更新式）。
  • 巢狀迴圈裡，兩者都只影響最近的那一層。
  • goto 標籤; 可以跳到同一個函數內的任意標籤處。老師的講義有介紹，但強調它會破壞程式結構，幾乎都能用迴圈與 break 取代，不建議使用。

Q1

預測輸出｜中break 與 continue

下面程式印出什麼？

C++
#include <iostream>
int main() {
    for (int i = 1; i <= 10; ++i) {
        if (i % 3 == 0) continue;
        if (i > 7) break;
        std::cout << i << " ";
    }
    std::cout << "\n";
}
答案
1 2 4 5 7

解析

3、6 被 continue 跳過；i = 8 時 8 > 7，break 結束迴圈（9 是 3 的倍數，但已經跑不到了）。

Q2

選擇｜中巢狀 break

在兩層 for 迴圈的內層執行 break，會發生什麼？

  1. (A)內外兩層迴圈都會一起結束
  2. (B)只結束內層，外層繼續下一次
  3. (C)結束整個程式，回傳 0
  4. (D)只跳過內層迴圈的這一次迭代
答案 (B)

只結束內層，外層繼續下一次

解析

break 只跳出最近的一層迴圈；要一次跳出多層，通常用旗標變數或把迴圈包成函數後 return。

4.9綜合應用：用迴圈解方程式

金融裡很多值沒有公式解，例如債券殖利率（YTM）、內部報酬率（IRR）——只能「猜一個值、看差多少、修正再猜」，直到夠準。這正是 while 迴圈的用武之地。

二分法求殖利率

債券價格是殖利率的遞減函數：殖利率越高，價格越低。已知市價，找出讓理論價等於市價的殖利率：

C++
#include <iostream>
#include <iomanip>
#include <cmath>

int main() {
    double face = 100, coupon = 0.03, market = 96.5;   // 5 年期、年付息 3% 的債券，市價 96.5
    int years = 5;

    double lo = 0.0, hi = 0.20, mid = 0;
    int iter = 0;
    while (hi - lo > 1e-10) {              // 區間夠小就停
        mid = (lo + hi) / 2;
        double price = 0;
        for (int t = 1; t <= years; ++t) {
            price += face * coupon / std::pow(1 + mid, t);
        }
        price += face / std::pow(1 + mid, years);
        if (price > market) {
            lo = mid;                      // 理論價太高 → 殖利率要再高一點
        } else {
            hi = mid;
        }
        ++iter;
    }
    std::cout << std::setprecision(8) << "YTM = " << mid * 100 << "%，迭代 " << iter << " 次\n";
    return 0;
}

YTM = 3.7813726%，迭代 31 次

每次把區間砍半，誤差從 0.2 縮小到 \(10^{-10}\) 只要 31 次。

牛頓法求 IRR

C++
#include <iostream>
#include <vector>
#include <cmath>

int main() {
    std::vector<double> cf = {-1000, 300, 400, 500, 200};   // 第 0 期投入 1000
    double r = 0.1;                                          // 初始猜測
    for (int iter = 1; iter <= 50; ++iter) {
        double npv = 0, dnpv = 0;
        for (std::size_t t = 0; t < cf.size(); ++t) {
            npv  += cf[t] / std::pow(1 + r, t);
            dnpv += -static_cast<double>(t) * cf[t] / std::pow(1 + r, t + 1);   // NPV 對 r 的導數
        }
        double r_new = r - npv / dnpv;                       // 牛頓法：沿切線找零點
        std::cout << "第 " << iter << " 次：r = " << r_new << "\n";
        if (std::abs(r_new - r) < 1e-12) {
            r = r_new;
            break;                                           // 收斂了
        }
        r = r_new;
    }
    std::cout << "IRR = " << r * 100 << "%\n";
    return 0;
}

第 1 次：r = 0.148757
第 2 次：r = 0.153189
第 3 次：r = 0.153221
第 4 次：r = 0.153221
第 5 次：r = 0.153221
IRR = 15.3221%
換個角度想二分法 vs 牛頓法

二分法很穩（只要區間兩端一正一負就一定收斂），但比較慢；牛頓法很快（通常 4～6 次），但需要導數，起始值太差時可能發散。實務上常先用二分法縮小範圍，再用牛頓法加速。這種「重複修正直到收斂」的結構——while (誤差 > 容忍值) 或 for + break——在數值方法裡隨處可見。

自編練習題（選擇、填空、預測輸出、找錯、寫程式），不是老師出的題目。寫程式題的參考答案都實際編譯執行過。

Q1

簡答｜中為什麼用 while

為什麼求殖利率的二分法適合用 while 而不是固定次數的 for？要讓程式更安全，應該再加上什麼條件？

答案

因為事前不知道要猜幾次才能達到精度，停止條件是「誤差小於容忍值」，所以用 while 表達最自然。為了避免意外狀況（例如區間設錯永遠不收斂）造成無窮迴圈，應該同時加上最大迭代次數的上限，例如 while (hi - lo > 1e-10 && iter < 200)。

Q2

寫程式｜難二分法求隱含報酬

一張零息債券 3 年後償還 100 元，現在價格 91 元。用二分法（區間 0～0.5）求年化殖利率 \(y\)，使 \(100/(1+y)^3 = 91\)，並與公式解 \(y = (100/91)^{1/3} - 1\) 比較。

答案
C++
#include <iostream>
#include <iomanip>
#include <cmath>

int main() {
    double lo = 0, hi = 0.5, mid = 0;
    int iter = 0;
    while (hi - lo > 1e-12 && iter < 200) {
        mid = (lo + hi) / 2;
        double price = 100 / std::pow(1 + mid, 3);
        if (price > 91) lo = mid; else hi = mid;
        ++iter;
    }
    std::cout << std::setprecision(10) << "二分法：" << mid << "\n";
    std::cout << "公式解：" << std::pow(100.0 / 91, 1.0 / 3) - 1 << "\n";
}

二分法：0.0319362513
公式解：0.0319362513

解析

零息債有公式解，可以拿來驗證數值方法寫得對不對——這是寫數值程式的好習慣：先在有答案的問題上測試。

4.10例外處理：throw、try、catch

遇到「處理不了的狀況」

程式執行時可能遇到超出正常範圍的狀況：資料檔打不開、輸入的利率是負的、要算的波動度只有一筆資料……這種時候與其印出錯誤的數字，不如丟出例外（throw an exception），讓有能力處理的地方去處理。

C++
#include <iostream>
#include <stdexcept>
#include <vector>
#include <cmath>

int main() {
    std::vector<std::vector<double>> datasets = {{0.01, -0.02, 0.015}, {0.03}};
    for (const auto &r : datasets) {
        try {
            if (r.size() < 2) {
                throw std::invalid_argument("至少需要兩筆資料才能算標準差");
            }
            double mean = 0;
            for (double x : r) mean += x;
            mean /= r.size();
            double ss = 0;
            for (double x : r) ss += (x - mean) * (x - mean);
            std::cout << "標準差 = " << std::sqrt(ss / (r.size() - 1)) << "\n";
        } catch (const std::invalid_argument &e) {
            std::cout << "資料有問題：" << e.what() << "\n";
        }
    }
    std::cout << "程式繼續執行\n";
    return 0;
}

標準差 = 0.0189297
資料有問題：至少需要兩筆資料才能算標準差
程式繼續執行
  • throw 表達式：發出例外，後面接一個例外物件，例如 std::runtime_error("訊息")、std::invalid_argument(...)（在 <stdexcept>）。
  • try { ... }：把可能出問題的程式碼包起來。
  • catch (例外型態 &e) { ... }：接住特定型態的例外並處理；e.what() 取得訊息。可以有好幾個 catch 分別處理不同型態。
  • throw 之後，try 區塊裡剩下的程式不會執行，直接跳到對應的 catch；處理完繼續執行 catch 後面的程式。
  • 沒有被任何 catch 接住的例外會讓程式終止（3.5 節 v.at(5) 的 terminate called after throwing... 就是這樣）。

接住標準程式庫丟出的例外：

C++
#include <iostream>
#include <vector>
#include <string>
#include <stdexcept>

int main() {
    std::vector<int> v = {1, 2, 3};
    try {
        std::cout << v.at(5) << "\n";
    } catch (const std::out_of_range &e) {
        std::cout << "超出範圍：" << e.what() << "\n";
    }

    try {
        double px = std::stod("N/A");          // 資料缺漏時常見
        std::cout << px << "\n";
    } catch (const std::exception &e) {        // std::exception 可以接住所有標準例外
        std::cout << "轉換失敗：" << e.what() << "\n";
    }
    return 0;
}

超出範圍：vector::_M_range_check: __n (which is 5) >= this->size() (which is 3)
轉換失敗：stod

標準例外定義在 <exception>、<stdexcept>、<new>、<typeinfo> 等標頭檔；常用的有 std::runtime_error、std::invalid_argument、std::out_of_range，它們都屬於 std::exception 這個大家族（第 8 章「繼承」會說明為什麼用父類別就能接住子類別）。

Q1

選擇｜中throw 之後

在 try 區塊中執行到 throw std::runtime_error("x"); 之後，會發生什麼？

  1. (A)印出訊息後繼續執行 try 區塊的下一行
  2. (B)跳到相符的 catch，try 剩下的不執行
  3. (C)不論有沒有對應的 catch，程式一定立刻終止
  4. (D)回到 try 區塊的第一行，重新執行一次

Q2

寫程式｜中輸入檢查

寫程式計算 Sharpe ratio \(=(R_p - R_f)/\sigma_p\)：當 \(\sigma_p \le 0\) 時丟出 std::invalid_argument，在 main 中用 try/catch 處理。分別測試 σ = 0.15 與 σ = 0。

答案
C++
#include <iostream>
#include <stdexcept>

int main() {
    double rp = 0.10, rf = 0.02;
    double sigmas[] = {0.15, 0.0};
    for (double s : sigmas) {
        try {
            if (s <= 0) throw std::invalid_argument("波動度必須大於 0");
            std::cout << "Sharpe = " << (rp - rf) / s << "\n";
        } catch (const std::invalid_argument &e) {
            std::cout << "錯誤：" << e.what() << "\n";
        }
    }
}

Sharpe = 0.533333
錯誤：波動度必須大於 0

解析

浮點數除以 0 在 C++ 不會讓程式崩潰，而是得到 inf，錯誤的數字會一路傳下去；主動檢查並丟出例外，問題才不會被藏起來。

4.11本章小結

  • 表達式由運算子與運算元組成；先看優先順序、再看結合律，不確定就加括號。
  • 型態轉換：小整數提升為 int、混合運算往大範圍轉、signed 與 unsigned 混用會出事；需要轉型用 static_cast。
  • 邏輯運算：&&、|| 有短路求值，可用來做安全檢查；i < j < k 要寫成 i < j && j < k；= 不是 ==。
  • 遞增：前置 ++i 回傳加完的自己（左值），後置 i++ 回傳原值副本（右值）；不需要原值就用前置。
  • 其他：-> 等於 (*p).、條件運算子 ? :、逗點運算子。
  • 語句：空語句、區塊與作用域；多一個分號就可能讓迴圈失效。
  • if / else：else 跟最近的 if 配對，永遠寫大括號；switch 只用於整數類型，記得 break。
  • 迴圈：for（知道次數）、while（直到條件達成）、do-while（至少一次）；break 結束迴圈、continue 跳過本次。
  • 數值方法（二分法、牛頓法）用「重複修正直到收斂」求殖利率與 IRR。
  • 例外處理：throw 丟出、try 包住、catch 接住，e.what() 取得訊息。
