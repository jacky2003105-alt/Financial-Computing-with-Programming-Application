3.1一維陣列

一排連續的置物櫃

陣列是「同一種型態、連續排在一起的一組變數」，用一個名字＋下標存取：

C++
#include <iostream>

int main() {
    double close[5] = {100.0, 101.5, 99.8, 102.3, 103.0};   // 5 天的收盤價
    std::cout << "第一天：" << close[0] << "\n";             // 下標從 0 開始！
    std::cout << "最後一天：" << close[4] << "\n";
    close[2] = 100.2;                                        // 元素就像普通變數，可以賦值
    double sum = 0;
    for (int i = 0; i < 5; i++) {
        sum += close[i];
    }
    std::cout << "平均：" << sum / 5 << "\n";
    std::cout << "整個陣列佔 " << sizeof(close) << " bytes，元素個數 = "
              << sizeof(close) / sizeof(close[0]) << "\n";
    return 0;
}

第一天：100
最後一天：103
平均：101.4
整個陣列佔 40 bytes，元素個數 = 5
  • 宣告：型態 名稱[元素個數]。double close[5] 有 5 個元素：close[0]～close[4]。
  • 下標從 0 開始，最後一個是「個數 − 1」。R 從 1 開始，這是轉換過來最容易錯的地方。
  • 陣列的大小必須在編譯時確定（字面值或 constexpr），不能是執行時才知道的變數。
  • sizeof(陣列) / sizeof(一個元素) 可以算出元素個數（只在宣告陣列的那個範圍內有效，傳進函數後就不行了，第 5 章會說明）。

初始化的各種情況

C++
#include <iostream>

int main() {
    int a[5] = {9, 8, 7, 6, 5};      // 全部給
    int b[5] = {9, 8};               // 只給一部分：其餘自動為 0
    int c[5] = {};                   // 全部為 0
    int d[] = {1, 2, 3};             // 全部給時可以省略長度，編譯器數出 3
    for (int i = 0; i < 5; i++) std::cout << b[i] << " ";
    std::cout << "\n";
    std::cout << "d 有 " << sizeof(d) / sizeof(d[0]) << " 個元素\n";
    return 0;
}

9 8 0 0 0 
d 有 3 個元素
  • 只定義不初始化（int a[5];，在函數裡）：元素是不確定的垃圾值。
  • 給部分初值時，其餘補 0——所以 int c[5] = {}; 是把陣列清成 0 的常用寫法。

越界：最危險的錯誤

C++
#include <iostream>

int main() {
    int guard1 = 111;
    int a[3] = {10, 20, 30};
    int guard2 = 222;
    std::cout << "a[2] = " << a[2] << "\n";
    // a[3] 不存在！但 C++ 不會阻止你讀它：
    std::cout << "a[3] = " << a[3] << "（讀到的是不屬於 a 的記憶體）\n";
    std::cout << guard1 << " " << guard2 << "\n";
    return 0;
}

a[2] = 30
a[3] = -334348544（讀到的是不屬於 a 的記憶體）
111 222

老師講義強調：使用 a[10]（超出範圍）時系統不會提示錯誤，但那塊記憶體不屬於你，寫進去可能蓋掉其他變數，造成「莫名其妙」的錯誤。讀到的值每次可能不同。R 越界會回傳 NA，C++ 不會——檢查下標是程式設計師自己的責任。

下面程式印出什麼？

C++
#include <iostream>

答案

Q3

寫程式｜中日報酬率

給定 6 天收盤價 {50.0, 51.0, 50.5, 52.0, 53.5, 53.0}，用陣列與 for 迴圈算出 5 個日報酬率（\(r_t = P_t / P_{t-1} - 1\)），存進另一個陣列，再印出每天報酬率（百分比）與平均日報酬率。

答案
C++
#include <iostream>
#include <iomanip>

int main() {
    double p[6] = {50.0, 51.0, 50.5, 52.0, 53.5, 53.0};
    double r[5];
    double sum = 0;
    std::cout << std::fixed << std::setprecision(3);
    for (int t = 1; t < 6; t++) {
        r[t - 1] = p[t] / p[t - 1] - 1;
        sum += r[t - 1];
        std::cout << "第 " << t << " 天：" << r[t - 1] * 100 << "%\n";
    }
    std::cout << "平均：" << sum / 5 * 100 << "%\n";
}

第 1 天：2.000%
第 2 天：-0.980%
第 3 天：2.970%
第 4 天：2.885%
第 5 天：-0.935%
平均：1.188%

解析

6 個價格只能算出 5 個報酬率；迴圈從 t = 1 開始，才能取用 p[t − 1]。如果從 t = 0 開始，就會讀到 p[−1]，越界。

3.2二維陣列

表格式資料

C++
#include <iostream>

int main() {
    // 3 檔股票 × 4 季的報酬率（%）
    double ret[3][4] = {
        { 2.1, -1.0,  3.5, 0.8},
        { 0.5,  1.2, -0.7, 2.0},
        {-1.5,  4.0,  1.1, 0.3}
    };
    for (int i = 0; i < 3; i++) {             // 外層：列（股票）
        double total = 0;
        for (int j = 0; j < 4; j++) {         // 內層：行（季）
            std::cout << ret[i][j] << "\t";
            total += ret[i][j];
        }
        std::cout << "| 合計 " << total << "\n";
    }
    std::cout << "列數 = " << sizeof(ret) / sizeof(ret[0])
              << "，行數 = " << sizeof(ret[0]) / sizeof(ret[0][0]) << "\n";
    return 0;
}

2.1	-1	3.5	0.8	| 合計 5.4
0.5	1.2	-0.7	2	| 合計 3
-1.5	4	1.1	0.3	| 合計 3.9
列數 = 3，行數 = 4
  • double ret[3][4]：3 列（rows）4 行（columns），共 12 個元素。寫成 ret[3, 4] 是錯的。
  • 老師的理解方式：二維陣列是「元素是一維陣列的一維陣列」——ret 有 3 個元素 ret[0]、ret[1]、ret[2]，每個都是 4 個 double 的陣列。
  • 記憶體中按列存放（row-major）：ret[0][0]、ret[0][1]、…、ret[0][3]、ret[1][0]…。最右邊的下標變化最快。（R 的矩陣剛好相反，是按行存放。）
  • 初始化可以按列分組 {{...}, {...}}，也可以一口氣寫 12 個數；部分初始化時其餘補 0；全部初始化時第一維可省略，其他維度不能省：int a[][4] = {...};。

3.3指標與陣列

陣列名稱就是首元素的位址

這是 C/C++ 最重要也最容易混淆的觀念：在大多數運算式中，陣列名稱會自動轉換成「指向第一個元素的指標」。

C++
#include <iostream>

int main() {
    int a[] = {100, 200, 300};
    int *p = a;                 // 不用寫 &a[0]：a 自動轉成 &a[0]
    std::cout << "a     = " << a << "\n";
    std::cout << "&a[0] = " << &a[0] << "\n";
    std::cout << "p     = " << p << "\n";          // 三個位址一樣

    std::cout << a[1] << " " << *(a + 1) << " " << *(p + 1) << " " << p[1] << "\n";
    std::cout << "p     = " << p << "\n";
    std::cout << "p + 1 = " << p + 1 << "（差 " << sizeof(int) << " bytes）\n";
    return 0;
}

a     = 0x7ffd2e4d711c
&a[0] = 0x7ffd2e4d711c
p     = 0x7ffd2e4d711c
200 200 200 200
p     = 0x7ffd2e4d711c
p + 1 = 0x7ffd2e4d7120（差 4 bytes）
  • 指標算術：p + 1 不是位址加 1，而是「往後一個元素」——int 就加 4 bytes，double 就加 8 bytes。所以 *(p + i) 就是 a[i]；事實上 a[i] 本來就被定義成 *(a + i)。
  • 陣列名稱像一個不能改的指標（老師說：Top-Level const），所以 a = a + 1;、++a 都是錯的；但普通指標 p 可以移動：
C++
#include <iostream>

int main() {
    double price[] = {10.0, 10.5, 11.2, 10.8};
    double *p = price;
    double *end = price + 4;          // 指向「最後一個元素的下一個位置」
    while (p != end) {                // 用指標走過整個陣列
        std::cout << *p << " ";
        ++p;
    }
    std::cout << "\n";
    return 0;
}

10 10.5 11.2 10.8

這種「從頭走到尾端的下一個位置」的寫法，就是後面迭代器的原型。

指向整個陣列的指標、陣列的參考

老師講義用「由內而外」讀複雜宣告：

C++
#include <iostream>

int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    int *ptrs[5];                 // 由右往左：ptrs 是 5 個元素的陣列，元素是 int*（指標的陣列）
    int (*parr)[5] = &arr;        // 先看括號：parr 是指標，指向「5 個 int 的陣列」（陣列的指標）
    int (&rarr)[5] = arr;         // 先看括號：rarr 是參考，綁定「5 個 int 的陣列」（陣列的參考）

    for (int i = 0; i < 5; i++) ptrs[i] = &arr[i];
    std::cout << *ptrs[2] << " " << (*parr)[3] << " " << rarr[4] << "\n";
    std::cout << "parr = " << parr << "，parr + 1 = " << parr + 1 << "（跳過整個陣列 20 bytes）\n";
    return 0;
}

3 4 5
parr = 0x7ffebad2b720，parr + 1 = 0x7ffebad2b734（跳過整個陣列 20 bytes）
  • int &refs[5]; 是錯的：參考不是物件，沒有「參考的陣列」。
  • parr + 1 一次跳過整個 5 個 int 的陣列——指標的型態決定「一步走多遠」。
  • 這些寫法在現代 C++ 很少需要自己寫，重點是理解「型態決定步伐」。

Q2

選擇｜中陣列名稱

int a[3] = {1, 2, 3}; int *p = a; 之後，下列哪一行無法編譯？

  2. (B)p++;

Q3

簡答｜中型態決定步伐

int *p 與 int (*q)[10] 都可以指向 int a[10] 的開頭（位址相同），為什麼 p + 1 與 q + 1 的位址不同？

答案

指標加 1 是「往後移動一個它所指的型態」。p 指向 int，加 1 移動 4 bytes（下一個元素）；q 指向「10 個 int 的陣列」，加 1 移動 40 bytes（跳過整個陣列）。位址相同，但型態不同，步伐就不同。

3.4字元陣列與 C 風格字串

字串就是以 '\0' 結尾的字元陣列

C++
#include <iostream>
#include <cstring>

int main() {
    char a[] = {'N', 'C', 'C', 'U'};          // 4 個字元，沒有結尾
    char b[] = "NCCU";                        // 字串字面值：自動加上 '\0'，共 5 個
    char c[] = {'N', 'C', 'C', 'U', '\0'};    // 和 b 等價
    std::cout << sizeof(a) << " " << sizeof(b) << " " << sizeof(c) << "\n";
    std::cout << "strlen(b) = " << std::strlen(b) << "\n";   // 長度不含 '\0'
    std::cout << b << "\n";
    char d[20] = "TAIEX";                     // 陣列可以比字串大
    std::cout << d << "，strlen = " << std::strlen(d) << "，sizeof = " << sizeof(d) << "\n";
    return 0;
}

4 5 5
strlen(b) = 4
NCCU
TAIEX，strlen = 5，sizeof = 20
  • C 語言沒有專門的字串型態，字串就是以結束字元 '\0' 結尾的字元陣列。
  • "NCCU" 看得到 4 個字元，實際佔 5 bytes，最後一個是 '\0'。
  • cout、printf、strlen 都是「從開頭一直讀到 '\0' 為止」。所以沒有 '\0' 的陣列 a 不能當字串印——會一路印下去，印出亂碼：
C++
#include <iostream>

int main() {
    char a[] = {'N', 'C', 'C', 'U'};    // 沒有 '\0'
    std::cout << a << "|\n";            // 未定義行為：可能多印出後面記憶體的內容
    return 0;
}

NCCU|

這次執行可能「剛好」印得正確（後面的記憶體碰巧是 0），但換一台電腦、換一個編譯選項就可能印出亂碼——未定義行為最可怕的地方就是有時候看起來沒事。

  • char c[4] = "NCCU"; 會編譯錯誤：放不下結尾的 '\0'。

字元陣列不能用 = 賦值

C++
#include <iostream>
#include <cstring>

int main() {
    char name[32];
    // name = "Bond A";                  // 錯誤：陣列不能賦值
    std::strcpy(name, "Bond A");        // 要用 strcpy 複製
    std::strcat(name, " 2030");         // strcat 接在後面
    std::cout << name << "，長度 " << std::strlen(name) << "\n";
    std::cout << std::strcmp("AAA", "BBB") << "\n";    // 比較：負數代表前者字典序較小
    return 0;
}

Bond A 2030，長度 11
-1

老師講義把 strcat、strcpy、strcmp、strlen 列為作業練習。它們很容易出錯：strcpy 不檢查目標陣列夠不夠大，寫爆了就越界。這正是要改用 std::string 的理由。

字元指標與 cout 的特殊待遇

C++
#include <iostream>

int main() {
    const char *p = "Hello Quant";     // 字串字面值是 const char 陣列，p 指向它的開頭
    std::cout << p << "\n";            // cout 對 char* 特別處理：印字串，不是位址
    std::cout << *p << "\n";           // 解參考：只有第一個字元 H
    std::cout << p + 6 << "\n";        // 從第 7 個字元開始印
    std::cout << static_cast<const void*>(p) << "\n";   // 真的要看位址，轉成 void*

    int nums[] = {1, 2, 3};
    std::cout << nums << "\n";         // int 陣列：印出位址
    return 0;
}

Hello Quant
H
Quant
0x55bb9e16f004
0x7fffe1ecdd5c

這解釋了第 2 章為什麼 &grade（char 的位址）要轉成 void* 才會印位址：cout 看到 char* 會假設它是 C 字串，從那裡一直印到 '\0'。

Q2

找錯｜中字元陣列賦值

下面程式為什麼無法編譯？請用兩種方式修正。

3.5std::vector：會長大的陣列

陣列的缺點

老師整理陣列的缺點：(1) 長度要在編譯時確定；(2) 定義後不能改變長度；(3) 不能整個賦值或複製；(4) 不能插入元素；(5) 無法直接得到長度（傳進函數後更是如此）。

C++ 標準程式庫的 std::vector 解決了所有這些問題。它是一個容器（container）：可以放一堆同型態的物件，而且會自動管理記憶體。

C++
#include <iostream>
#include <vector>                          // 使用 vector 要 include

int main() {
    std::vector<double> prices;            // 空的 vector，裡面放 double
    prices.push_back(100.0);               // 從尾端加入
    prices.push_back(101.5);
    prices.push_back(99.8);
    std::cout << "目前有 " << prices.size() << " 筆\n";
    std::cout << "第二筆：" << prices[1] << "\n";

    std::vector<double> backup = prices;   // 可以整個複製！
    prices.push_back(102.3);
    std::cout << "prices 有 " << prices.size() << " 筆，backup 有 " << backup.size() << " 筆\n";
    return 0;
}

目前有 3 筆
第二筆：101.5
prices 有 4 筆，backup 有 3 筆
  • std::vector<double>：角括號裡寫元素型態。老師的說法：vector 本身是一個類別模板（class template），vector<double> 才是「實例化」後完整的型態（第 9 章介紹模板）。
  • 元素可以是任何物件型態：vector<int*>、vector<std::string>、vector<Bond>（自己的 struct）、vector<vector<double>>；但不能是參考 vector<int&>（參考不是物件）。

各種初始化：() 是個數、{} 是內容

range for：走過每個元素

C++
#include <iostream>
#include <vector>

int main() {
    std::vector<double> w = {0.5, 0.3, 0.2};      // 投資組合權重
    std::vector<double> r = {0.08, 0.12, 0.03};   // 各資產預期報酬

    double sum_w = 0;
    for (double x : w) sum_w += x;                // 唯讀：x 是每個元素的副本
    std::cout << "權重合計 = " << sum_w << "\n";

    for (double &x : r) x = x * 100;              // 要修改：用參考 &
    for (auto x : r) std::cout << x << "% ";      // auto：讓編譯器推論型態
    std::cout << "\n";

    double port = 0;
    for (std::size_t i = 0; i < w.size(); i++)     // 需要下標時用傳統 for
        port += w[i] * r[i];
    std::cout << "組合預期報酬 = " << port << "%\n";
    return 0;
}

二維 vector：蒙地卡羅模擬的矩陣

老師講義用二維 vector 存 1000 條路徑 × 365 天的常態亂數：

C++
#include <iostream>
#include <vector>
#include <random>
#include <cmath>

int main() {
    const int paths = 1000, days = 252;
    std::default_random_engine gen(42);                    // 固定種子：每次結果相同
    std::normal_distribution<double> z(0.0, 1.0);          // 標準常態分配

    // paths 列，每列是一個長度 days 的 vector<double>
    std::vector<std::vector<double>> price(paths, std::vector<double>(days + 1));
    double S0 = 100, mu = 0.06, sigma = 0.2, dt = 1.0 / 252;
    for (int i = 0; i < paths; i++) {
        price[i][0] = S0;
        for (int t = 1; t <= days; t++) {
            price[i][t] = price[i][t - 1] *
                std::exp((mu - 0.5 * sigma * sigma) * dt + sigma * std::sqrt(dt) * z(gen));
        }
    }
    double avg = 0;
    for (int i = 0; i < paths; i++) avg += price[i][days];
    std::cout << "前三條路徑的期末價：" << price[0][days] << "  "
              << price[1][days] << "  " << price[2][days] << "\n";
    std::cout << "期末平均價 = " << avg / paths << "（理論值 " << S0 * std::exp(mu) << "）\n";
    return 0;
}

前三條路徑的期末價：87.3063  71.2608  106.754
期末平均價 = 106.125（理論值 106.184）
  • std::vector<std::vector<double>> price(paths, std::vector<double>(days + 1));：外層 paths 個元素，每個元素是「days + 1 個 double 的 vector」。
  • <random>：default_random_engine 是亂數產生器，normal_distribution 把它轉成常態亂數；種子固定為 42，所以結果可重現（研究與除錯時很重要）。
  • 這就是幾何布朗運動的模擬，選擇權定價課程會一直用到。

需要「長度固定、很小、追求極致效能」時用陣列（或 C++11 的 std::array<double, 5>）；其他幾乎所有情況用 vector。下一章之後的範例都以 vector 為主。

用 vector 存放報酬率 {0.012, -0.008, 0.021, 0.004, -0.015, 0.009}，計算平均數與樣本標準差（分母 n − 1），再年化波動度（日標準差 × √252）。

答案
C++
#include <iostream>
#include <vector>
#include <cmath>

int main() {
    std::vector<double> r = {0.012, -0.008, 0.021, 0.004, -0.015, 0.009};
    double sum = 0;
    for (double x : r) sum += x;
    double mean = sum / r.size();

              << "\n年化波動度 = " << sd * std::sqrt(252.0) << "\n";
}

為什麼用 string

std::string 是標準程式庫的可變長度字串型態：自己管記憶體、可以用 = 賦值、用 + 相接、用 == 比較、隨時知道長度——C 風格字元陣列做不到或很危險的事，它都能安全地做。

字串 "2330,1000,1015.5" 分別是代號、股數、價格。用 find、substr、stoi、stod 拆開，印出「2330 成交金額 1015500」。

C++
#include <iostream>
#include <iomanip>
#include <string>

int main() {
    std::string rec = "2330,1000,1015.5";
    std::size_t p1 = rec.find(',');
    std::size_t p2 = rec.find(',', p1 + 1);           // 從 p1 之後找第二個逗號

    std::cout << std::fixed << std::setprecision(0);   // 不要用科學記號

}

2330 成交金額 1015500

解析

find(字元, 起點) 可以從指定位置開始找；substr(起點, 長度) 的第二個參數是長度，不是終點。1015500 有 7 位數，cout 預設只顯示 6 位有效數字，會變成科學記號 1.0155e+06，所以用 std::fixed 搭配 setprecision(0)。

3.7迭代器：統一的「走訪」方式

迭代器就像容器專用的指標

迭代器（iterator）用來走過容器裡的元素。它的用法和 3.3 節走陣列的指標幾乎一樣：*it 取元素、++it 往下一個、和尾端比較決定何時停。不同的是，每種容器（vector、string、list、map…）都有自己的迭代器，但用法統一。

C++
#include <iostream>
#include <vector>

int main() {
    std::vector<int> iv = {100, 200, 300};
    for (std::vector<int>::iterator it = iv.begin(); it != iv.end(); ++it) {
        std::cout << *it << " ";
        *it += 1;                               // 透過迭代器修改元素
    }
    std::cout << "\n";
    for (auto rit = iv.rbegin(); rit != iv.rend(); ++rit)   // 反向迭代器
        std::cout << *rit << " ";
    std::cout << "\n";

    std::vector<int> empty;
    std::cout << std::boolalpha << (empty.begin() == empty.end()) << "\n";  // 空容器：begin == end
    return 0;
}

100 200 300 
301 201 101 
true
  • begin() 指向第一個元素；end() 指向「最後一個元素的下一個位置」——一個不存在的元素，只當作終點標記，不能解參考。
  • 容器為空時 begin() == end()。
  • rbegin() 指向最後一個元素、rend() 指向第一個元素「之前」，用來反向走。
  • 型態名稱 std::vector<int>::iterator 很長，通常寫 auto。

迭代器運算子

運算 意義
*it 取得迭代器指向的元素（end() 不能用）
it->member 等於 (*it).member（元素是 struct 時）
++it / --it 移到下一個／上一個元素
it1 == it2 / != 是否指向同一個元素
it + n、it2 - it1 跳 n 個、兩者距離（vector、string 才支援，list 要用 std::advance）
C++
#include <iostream>
#include <vector>
#include <string>

struct Holding { std::string ticker; int shares; };

int main() {
    std::vector<Holding> book;
    Holding h = {"2330", 1000};
    book.push_back(h);          // 複製一份進容器
    h.shares = 5000;            // 改原本的 h，不影響容器裡的副本
    book.push_back({"2317", 2000});

    for (auto it = book.begin(); it != book.end(); ++it) {
        std::cout << it->ticker << "：" << (*it).shares << " 股\n";
    }
    auto last = book.end() - 1;                 // vector 的迭代器可以做加減
    std::cout << "最後一筆是 " << last->ticker << "，與開頭距離 " << last - book.begin() << "\n";
    return 0;
}

2330：1000 股
2317：2000 股
最後一筆是 2317，與開頭距離 1

const_iterator：唯讀走訪

C++
#include <vector>
int main() {
    std::vector<int> iv = {100, 200, 300};

        *it = 99;            // 錯誤：cbegin/cend 回傳 const_iterator，不能透過它修改
    }
    return 0;
}

  • const_iterator 只能讀不能改元素（迭代器自己可以移動）——類似第 2 章「指向常數的指標」。
  • 容器本身是 const 時，begin() 自動回傳 const_iterator。C++11 的 cbegin()／cend() 明確表示「我只要讀」。

迭代器失效

老師講義的提醒：任何改變容器大小的操作（如 push_back、erase）都可能讓現有的迭代器、指標、參考失效。vector 的元素是連續存放的，空間不夠時會整塊搬到新的記憶體，原本指向舊位置的迭代器就變成「無效指標」：

C++
#include <iostream>
#include <vector>

int main() {
    std::vector<int> v = {1, 2, 3};
    std::cout << "容量 " << v.capacity() << "，首元素位址 " << &v[0] << "\n";
    v.push_back(4);                    // 容量不夠 → 搬家
    std::cout << "容量 " << v.capacity() << "，首元素位址 " << &v[0] << "\n";
    // 搬家前取得的迭代器、指標，現在都指向舊的（已釋放的）記憶體
    return 0;
}

容量 3，首元素位址 0x55757511b2b0
容量 6，首元素位址 0x55757511c2e0

迭代器 + 演算法

迭代器真正強大的地方是搭配 <algorithm>：同一套演算法可以用在任何容器上，只要給它「從哪裡到哪裡」（一對迭代器）。

C++
#include <iostream>
#include <vector>
#include <algorithm>
#include <numeric>

int main() {
    std::vector<double> r = {0.012, -0.031, 0.021, 0.004, -0.015, 0.009, -0.002};

    std::vector<double> s = r;
    std::sort(s.begin(), s.end());                                  // 由小到大排序
    std::cout << "最差：" << s.front() << "，最好：" << s.back() << "\n";

    auto it = std::max_element(r.begin(), r.end());                 // 最大值的位置
    std::cout << "最大報酬在第 " << it - r.begin() + 1 << " 天：" << *it << "\n";

    double total = std::accumulate(r.begin(), r.end(), 0.0);        // 加總（<numeric>）
    int losses = std::count_if(r.begin(), r.end(), [](double x) { return x < 0; });
    std::cout << "合計 " << total << "，虧損天數 " << losses << "\n";

    std::sort(s.begin(), s.end(), [](double a, double b) { return a > b; });   // 由大到小
    std::cout << "前三名：" << s[0] << " " << s[1] << " " << s[2] << "\n";
    return 0;
}

最差：-0.031，最好：0.021
最大報酬在第 3 天：0.021
合計 -0.002，虧損天數 3
前三名：0.021 0.012 0.009
  • std::sort(begin, end)、std::max_element、std::min_element、std::find、std::count_if、std::accumulate（加總，在 <numeric>，第三個參數 0.0 決定累加的型態，寫成 0 會變成整數加總！）。
  • [](double x) { return x < 0; } 是 lambda：一個寫在原地、沒有名字的小函數，用來告訴演算法「條件」或「排序規則」。第 5 章會介紹。
金融應用歷史模擬法 VaR

把 N 天的報酬率排序，第 5% 分位數的損失就是 95% 信心水準的風險值（VaR）：

C++
#include <iostream>
#include <vector>
#include <algorithm>
#include <random>

int main() {
    std::default_random_engine gen(7);
    std::normal_distribution<double> d(0.0005, 0.015);
    std::vector<double> r(500);
    for (double &x : r) x = d(gen);                // 用模擬資料代替 500 天歷史報酬

    std::sort(r.begin(), r.end());
    std::size_t k = static_cast<std::size_t>(0.05 * r.size());   // 第 5% 的位置
    double position = 10'000'000;                  // 部位 1000 萬
    std::cout << "第 5% 分位報酬 = " << r[k] << "\n";
    std::cout << "一日 95% VaR ≈ " << -r[k] * position << " 元\n";
    return 0;
}

第 5% 分位報酬 = -0.0237199
一日 95% VaR ≈ 237199 元

Concept Check：3.7 迭代器：統一的「走訪」方式

自編練習題（選擇、填空、預測輸出、找錯、寫程式），不是老師出的題目。寫程式題的參考答案都實際編譯執行過。

Q1

選擇｜易end()

關於 v.end()，下列何者正確？

  1. (A)指向 vector 的最後一個元素
  2. (B)指向最後一個元素的下一個位置，不能解參考
  3. (C)回傳 vector 的元素個數
  4. (D)指向 vector 的第一個元素前面的位置
答案 (B)

指向最後一個元素的下一個位置，不能解參考

解析

end() 是「尾後」位置，只當作結束標記；最後一個元素要用 end() - 1、back() 或 rbegin()。

Q2

選擇｜中const_iterator

for (auto it = v.cbegin(); it != v.cend(); ++it) 這個迴圈中，下列何者不允許？

  1. (A)*it = 0;
  2. (B)std::cout << *it;
  3. (C)++it
  4. (D)it != v.cend()
答案 (A)*it = 0;

解析

const_iterator 指向的元素是唯讀的；迭代器本身可以移動與比較。

Q3

簡答｜中迭代器失效

為什麼「一邊用迭代器走 vector、一邊 push_back」很危險？

答案

vector 的元素存放在一塊連續記憶體，push_back 時若容量不足，會配置一塊更大的記憶體並把所有元素搬過去，舊的記憶體被釋放。原本的迭代器（以及指標、參考）仍指向舊位置，變成失效的迭代器，再使用會造成未定義行為。

Q4

寫程式｜中排序與中位數

給定一組基金年報酬 {5.2, -3.1, 12.4, 8.0, 0.7, 15.3, -6.2}（%），用 std::sort 排序後印出由小到大的結果與中位數，再用 std::count_if 算出報酬超過 5% 的基金數。

答案
C++
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<double> f = {5.2, -3.1, 12.4, 8.0, 0.7, 15.3, -6.2};
    std::sort(f.begin(), f.end());
    for (double x : f) std::cout << x << " ";
    std::cout << "\n中位數 = " << f[f.size() / 2] << "\n";
    int n = std::count_if(f.begin(), f.end(), [](double x) { return x > 5; });
    std::cout << "超過 5% 的有 " << n << " 檔\n";
}

-6.2 -3.1 0.7 5.2 8 12.4 15.3 
中位數 = 5.2
超過 5% 的有 4 檔

解析

7 個元素時中位數在下標 3；若個數是偶數，中位數要取中間兩個的平均。

3.8本章小結

  • 陣列：型態 名[固定長度]，下標從 0 開始，越界不會報錯但很危險；不能整個複製或賦值；二維陣列按列存放。
  • 陣列與指標：陣列名稱會轉成首元素的位址；a[i] 等於 *(a + i)；指標加 1 是走一個「它所指的型態」那麼遠。
  • C 字串：以 '\0' 結尾的字元陣列；cout 對 char* 會印字串而不是位址；strcpy、strcat 容易越界。
  • std::vector<T>：可變長度、可複製比較；() 是個數、{} 是內容；push_back、size、at、range for（要改元素用 &）。
  • std::string：+ 相接、== 比較、getline 讀整列、find／substr 切割、stod／to_string 轉換。
  • 迭代器：begin()／end()（尾後位置）、*it、++it、it->；const_iterator 唯讀；改變容器大小會讓迭代器失效；搭配 <algorithm> 的 sort、max_element、count_if、accumulate 處理資料。
