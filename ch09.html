這一章對應講義七：模板（template）與泛型程式設計。你其實已經用了很久——std::vector<double>、std::shared_ptr<Bond>、std::sort 都是模板。老師的說法：就算自己不常寫模板，要讀懂 QuantLib、標準程式庫這種大型程式庫，模板是繞不過去的。本章從函數模板、類別模板開始，接著是 typename、成員函數模板、模板的實例化與分離編譯、別名、特化，最後是可變參數模板與模板模板參數。

9.1為什麼需要模板

同一段邏輯，不同的型態

第 5 章的函數重載可以讓 max(int, int)、max(double, double) 共用一個名字，但每個版本都要重寫一次，邏輯完全一樣：

C++
int    max_of(int a, int b)       { return a > b ? a : b; }
double max_of(double a, double b) { return a > b ? a : b; }
// long long、float、std::string、自己的 Money 類別……要寫到什麼時候？

模板讓你把型態當成參數，寫一次就適用所有型態：

C++
#include <iostream>
#include <string>

template <typename T>                 // T 是「型態參數」：代表某個尚未決定的型態
T max_of(const T &a, const T &b) {
    return a > b ? a : b;
}

int main() {
    std::cout << max_of(3, 7) << "\n";                       // T = int
    std::cout << max_of(2.5, 1.8) << "\n";                   // T = double
    std::cout << max_of(std::string("AAPL"), std::string("MSFT")) << "\n";   // T = std::string
    return 0;
}

7
2.5
MSFT
  • 模板是「產生函數（或類別）的藍圖」：template <typename T> 宣告一個型態參數 T。
  • 呼叫 max_of(3, 7) 時，編譯器從實參推論出 T = int，再用 int 代入藍圖，產生一個真正的 int max_of(const int&, const int&)——這個過程叫實例化（instantiation）。
  • 一切都發生在編譯期：執行時就跟手寫的函數一模一樣，沒有額外成本。

泛型 vs 多型

多型（第 8 章） 泛型（模板）
何時決定 執行期（虛函數、vtable） 編譯期（實例化）
型態需要有關係嗎 要繼承同一個父類別 不用，只要支援用到的操作
代價 每次呼叫查 vtable 每種型態各產生一份程式碼（程式碼膨脹）
例子 Instrument* 指向各種商品 std::vector<T>、std::sort

兩者常一起使用：QuantLib 用模板寫通用的曲線、插值、數值方法，用虛函數組成商品與引擎的架構。

Q1

選擇｜易模板的本質

關於函數模板，下列何者正確？

  1. (A)程式執行時才決定 T 到底是什麼型態
  2. (B)編譯器依實際型態，產生出真正的函數
  3. (C)每次呼叫模板函數都比一般函數來得慢
  4. (D)模板只能搭配 int 與 double 這兩種型態
答案 (B)

編譯器依實際型態，產生出真正的函數

解析

模板是藍圖，編譯期依實際型態產生具體函數；產生出來的函數和手寫的一樣快。

9.2函數模板

定義與型態推論

C++
#include <iostream>
#include <vector>

template <typename T>
int compare(const T &v1, const T &v2) {     // 老師講義的例子：只要求 T 支援 <
    if (v1 < v2) return -1;
    if (v2 < v1) return 1;
    return 0;
}

template <typename T>
T sum(const std::vector<T> &v) {            // 參數型態也可以包含 T
    T s{};                                  // T{}：該型態的「零值」（int 為 0、double 為 0.0）
    for (const T &x : v) s += x;
    return s;
}

template <typename T, typename U, typename W>
auto add3(T a, U b, W c) { return a + b + c; }   // 多個型態參數；回傳型態用 auto 推論

int main() {
    std::cout << compare(1, 2) << " " << compare(3.5, 1.2) << "\n";
    std::cout << sum(std::vector<int>{1, 2, 3}) << " " << sum(std::vector<double>{0.1, 0.2}) << "\n";
    std::cout << add3(1, 2.5, 3) << "\n";        // T=int, U=double, W=int
    return 0;
}

非型態模板參數

模板參數也可以是一個值（必須是編譯期常數）：

C++
#include <iostream>
#include <cmath>

template <int N>                                    // N 是一個整數值，不是型態
double compound(double r) {
    return std::pow(1 + r / N, N) - 1;              // 每年 N 次複利的有效年利率
}

template <typename T, std::size_t N>
T average(const T (&arr)[N]) {                      // 陣列長度 N 由編譯器自動推論！
    T s{};
    for (const T &x : arr) s += x;
    return s / N;
}

int main() {
    std::cout << compound<1>(0.06) << " " << compound<12>(0.06) << " " << compound<365>(0.06) << "\n";
    double r[] = {0.01, 0.03, -0.02, 0.04};
    std::cout << "平均 " << average(r) << "（N 被推論為 4）\n";
    int n = 4;
    // compound<n>(0.06);                           // 錯誤：n 不是編譯期常數
    constexpr int M = 4;
    std::cout << compound<M>(0.06) << "\n";         // constexpr 可以
    return 0;
}

0.06 0.0616778 0.0618313
平均 0.015（N 被推論為 4）
0.0613636
  • template <int N>：用型態名稱（int、std::size_t）而不是 typename 宣告，代表一個值。
  • 實參必須是常數表達式——模板在編譯期實例化，執行期才知道的變數不能用。
  • std::array<double, 5> 的 5 就是非型態模板參數。

函數模板的全特化

某個特定型態需要不同的做法時，可以提供特化版本：

C++
#include <iostream>
#include <cstring>

template <typename T>
bool is_equal(const T &a, const T &b) { return a == b; }

template <>                                        // 全特化：T = const char* 時用這個版本
bool is_equal<const char*>(const char *const &a, const char *const &b) {
    return std::strcmp(a, b) == 0;                 // 比較字串內容，而不是比較指標
}

template <>                                        // double 用容忍誤差比較
bool is_equal<double>(const double &a, const double &b) {
    return (a > b ? a - b : b - a) < 1e-12;
}

int main() {
    const char *x = "TSMC";
    char buf[] = "TSMC";
    const char *y = buf;
    std::cout << std::boolalpha << is_equal(x, y) << " " << is_equal(0.1 + 0.2, 0.3) << " " << is_equal(3, 3) << "\n";
    return 0;
}

true true true
  • 語法：template <> 加上 函數名<具體型態>(...)。
  • 介面不變（使用者還是呼叫 is_equal），只是特定型態走特別的實作。
  • 函數模板只能全特化，不能局部特化；需要類似效果時改用重載。

Q1

選擇｜中推論失敗

template <typename T> T mul(T a, T b); 之下，mul(2, 1.5) 為什麼無法編譯？

  1. (A)兩個實參推論出的 T 不一致
  2. (B)模板函數的參數不能直接傳字面值
  3. (C)mul 這個名稱是 C++ 的保留字
  4. (D)呼叫模板函數時一定要寫出角括號
答案 (A)

兩個實參推論出的 T 不一致

解析

第一個實參推論出 T = int、第二個推論出 T = double，同一個 T 不能同時是兩種型態。可以寫 mul(2, 1.5)，或把模板改成兩個型態參數。

Q3

寫程式｜中通用的加權平均

寫一個函數模板 weighted_mean(const std::vector<T> &x, const std::vector<T> &w) 回傳加權平均（Σwx / Σw），分別用 double 與 float 測試：報酬 {0.08, 0.12, 0.03}、權重 {0.5, 0.3, 0.2}。

答案
C++
#include <iostream>
#include <vector>

template <typename T>
T weighted_mean(const std::vector<T> &x, const std::vector<T> &w) {
    T num{}, den{};
    for (std::size_t i = 0; i < x.size(); ++i) {
        num += w[i] * x[i];
        den += w[i];
    }
    return num / den;
}

int main() {
    std::cout << weighted_mean<double>({0.08, 0.12, 0.03}, {0.5, 0.3, 0.2}) << "\n";
    std::cout << weighted_mean<float>({0.08f, 0.12f, 0.03f}, {0.5f, 0.3f, 0.2f}) << "\n";
}

0.082
0.082

解析

用 {...} 傳入時編譯器無法從初始化列表推論 T，所以要明確寫 <double>；若先宣告好 vector 變數再傳，就能自動推論。

9.3類別模板

定義與使用

C++
#include <iostream>
#include <string>
#include <vector>

template <typename T>
class TimeSeries {                                   // 「T 型態值的時間序列」
public:
    void add(const std::string &date, const T &value) {
        dates_.push_back(date);
        values_.push_back(value);
    }
    std::size_t size() const { return values_.size(); }
    const T &last() const { return values_.back(); }
    T mean() const;                                  // 宣告，定義在類別外
private:
    std::vector<std::string> dates_;
    std::vector<T> values_;
};

template <typename T>                                // 類別外定義成員函數：要再寫一次 template
T TimeSeries<T>::mean() const {                      // 而且類別名要寫成 TimeSeries<T>
    T s{};
    for (const T &v : values_) s += v;
    return s / static_cast<T>(values_.size());
}

int main() {
    TimeSeries<double> px;                           // 類別模板一定要寫 <型態>
    px.add("2026-11-10", 1012.5);
    px.add("2026-11-11", 998.0);
    px.add("2026-11-12", 1015.0);
    std::cout << "最新 " << px.last() << "，平均 " << px.mean() << "\n";

    TimeSeries<long long> vol;                       // 同一個藍圖，另一種型態
    vol.add("2026-11-12", 35020);
    std::cout << "成交量筆數 " << vol.size() << "\n";
    return 0;
}

最新 1015，平均 1008.5
成交量筆數 1
  • template <typename T> class 名稱 { ... };：類別裡可以把 T 當成一般型態使用。
  • 使用時要寫 TimeSeries<double>——TimeSeries 只是模板，TimeSeries<double> 才是完整的型態（就像 std::vector 與 std::vector<double>，第 3 章）。
  • 在類別外定義成員函數：前面加 template <typename T>，類別名寫 TimeSeries<T>::。
  • 實例化時，只有真正被呼叫到的成員函數才會被產生。
  • C++17 起，建構時若能從參數推論，可省略 <>（例如 std::vector v{1.0, 2.0};），但初學時建議都寫出來。

類別模板的特化

C++
#include <iostream>
#include <string>

template <typename T>
class Formatter {                                    // 一般版本
public:
    static std::string show(const T &x) { return std::to_string(x); }
};

template <>
class Formatter<bool> {                              // 全特化：bool 印成文字
public:
    static std::string show(bool x) { return x ? "是" : "否"; }
};

template <typename T>
class Formatter<T*> {                                // 局部特化（偏特化）：任何指標型態
public:
    static std::string show(T *p) { return p ? "指向 " + Formatter<T>::show(*p) : "空指標"; }
};

int main() {
    double px = 101.25;
    double *pp = &px;
    double *np = nullptr;
    std::cout << Formatter<int>::show(42) << " | " << Formatter<bool>::show(true) << " | "
              << Formatter<double*>::show(pp) << " | " << Formatter<double*>::show(np) << "\n";
    return 0;
}

42 | 是 | 指向 101.250000 | 空指標
  • 全特化（full specialization）：所有模板參數都換成具體型態——Formatter<bool>。
  • 局部特化（partial specialization，偏特化）：只固定一部分，或只限制型態的「形狀」——Formatter<T*> 適用於所有指標型態；MyPair<int, U> 適用於第一個參數是 int 的情況。
  • 只有類別模板可以局部特化，函數模板不行。
  • 老師講義提到：QuantLib 用局部特化來分類型態（例如判斷某個型態是不是指標），用全特化來精準處理特定型態。這類「關於型態的資訊」的類別叫 traits：
C++
#include <iostream>

template <typename T> struct Traits      { static constexpr bool is_pointer = false; };
template <typename T> struct Traits<T*>  { static constexpr bool is_pointer = true;  };

int main() {
    std::cout << std::boolalpha << Traits<int>::is_pointer << " " << Traits<double*>::is_pointer << "\n";
    return 0;
}

false true

（標準程式庫的 <type_traits> 提供了大量現成的，例如 std::is_pointer<T>::value、std::is_floating_point_v<T>。）

9.4typename、成員函數模板與別名

typename 的第二個用途：相依型態名稱

typename 除了宣告型態參數，還有一個用途：在模板內部，依賴模板參數的名稱（例如 T::value_type），編譯器不知道它是型態還是靜態成員變數，預設當成「值」。如果它是型態，必須在前面加 typename：

C++
#include <iostream>
#include <vector>
#include <list>

template <typename Container>
typename Container::value_type first_element(const Container &c) {   // 回傳型態依賴 Container
    typename Container::const_iterator it = c.begin();               // 宣告依賴型態的變數
    return *it;
}

int main() {
    std::vector<double> v = {1.5, 2.5};
    std::list<int> l = {7, 8, 9};
    std::cout << first_element(v) << " " << first_element(l) << "\n";
    return 0;
}

1.5 7

規則：名稱依賴模板參數、又是一個型態時，前面一定要寫 typename。（現代寫法常用 auto 避開，但讀程式庫原始碼時會一直看到它。）

成員函數模板

一般類別（或類別模板）的成員函數本身也可以是模板：

C++
#include <iostream>
#include <string>

class Logger {
public:
    template <typename T>                     // 成員函數模板：任何型態都能記錄
    void log(const std::string &key, const T &value) {
        std::cout << "[" << ++n_ << "] " << key << " = " << value << "\n";
    }
private:
    int n_ = 0;
};

int main() {
    Logger lg;
    lg.log("price", 101.25);
    lg.log("qty", 1000);
    lg.log("ticker", std::string("2330"));
    return 0;
}

[1] price = 101.25
[2] qty = 1000
[3] ticker = 2330

成員函數模板不能是虛函數：vtable 在編譯期就要知道每個虛函數的確切簽名與位址，但函數模板是「函數產生器」，沒有固定的簽名（要用哪些型態實例化，編譯器事先不知道）。反過來，類別模板裡的一般成員函數可以是 virtual。

Q1

簡答｜中typename 的必要性

在模板中寫 T::iterator it; 為什麼可能編譯失敗？要怎麼修正？

答案

T::iterator 依賴模板參數 T，編譯器在看到模板定義時還不知道 T 是什麼，無法判斷 T::iterator 是型態還是靜態成員變數，預設會當成值來解析，於是 T::iterator it; 變成不合法的語法。修正方式是加上 typename，明確告訴編譯器它是型態：typename T::iterator it;（或改用 auto it = c.begin();）。

Q2

選擇｜中成員函數模板

為什麼成員函數模板不能宣告為 virtual？

  1. (A)虛函數表無法預先列出所有實例化版本
  2. (B)模板函數不能有任何回傳值
  3. (C)虛函數只能出現在類別模板之中
  4. (D)成員函數模板一律被視為 static
答案 (A)

虛函數表無法預先列出所有實例化版本

解析

虛函數表要列出每個虛函數的確切位址；函數模板可能被任意多種型態實例化，編譯器無法事先建立表格。

9.5模板的編譯：為什麼放在標頭檔

一般函數可以「宣告放 .h、定義放 .cpp」（第 5 章）；模板通常整個放在標頭檔。原因：編譯器要實例化 TimeSeries<double>，就必須在那個 .cpp 檔裡看得到模板的完整定義。如果定義藏在另一個 .cpp，編譯使用端時無法產生程式碼，到連結時就會出現 undefined reference：

C++ 檔案：avg.h
// avg.h：只有宣告
template <typename T>
T average(const T *x, int n);
C++ 檔案：avg.cpp
// avg.cpp：定義在這裡，但沒有人要求它實例化任何型態
#include "avg.h"
template <typename T>
T average(const T *x, int n) {
    T s{};
    for (int i = 0; i < n; ++i) s += x[i];
    return s / n;
}
C++
#include <iostream>
#include "avg.h"

int main() {
    double r[] = {0.01, 0.02, 0.03};
    std::cout << average(r, 3) << "\n";     // 連結錯誤：average<double> 沒有被產生
    return 0;
}

ld（連結器）: main.o: in function `main':
main.cpp:(.text+0x4f): undefined reference to `double average<double>(double const*, int)'
collect2: error: ld returned 1 exit status

兩種解法：

  1. 把模板的定義放在標頭檔（最常見；標準程式庫幾乎都是這樣）。缺點是每個 include 它的檔案都要重新編譯模板，大型專案編譯會變慢。
  2. 顯式實例化（explicit instantiation）：在 .cpp 的模板定義之後寫 template double average<double>(const double*, int);，強迫編譯器在那裡產生指定型態的版本；其他檔案可以用 extern template ...; 宣告「不用在這裡實例化，別處已經有了」。適合事先知道只會用到哪幾種型態、又想縮短編譯時間的情況。
C++ 檔案：avg2.cpp
#include "avg.h"
template <typename T>
T average(const T *x, int n) {
    T s{};
    for (int i = 0; i < n; ++i) s += x[i];
    return s / n;
}
template double average<double>(const double *, int);   // 顯式實例化：產生 double 版本
C++
#include <iostream>
#include "avg.h"

int main() {
    double r[] = {0.01, 0.02, 0.03};
    std::cout << average(r, 3) << "\n";     // 這次連結得到
    return 0;
}

0.02

老師講義也提到模板編譯錯誤的三個階段：定義時（只查語法）、使用時（查參數個數）、實例化時（型態相關的錯誤這時才出現）。

自編練習題（選擇、填空、預測輸出、找錯、寫程式），不是老師出的題目。寫程式題的參考答案都實際編譯執行過。

Q1

簡答｜中模板放標頭檔

為什麼函數模板的定義通常要寫在標頭檔，而不是像一般函數一樣放在 .cpp？

答案

模板本身不是程式碼，只有在某個編譯單元中用具體型態實例化時，編譯器才會產生程式碼，而實例化需要看到模板的完整定義。若定義只放在另一個 .cpp，使用端編譯時看不到定義，無法實例化；定義所在的 .cpp 又沒有人要求它產生該型態的版本，最後連結時找不到函數。把定義放在標頭檔，每個使用的檔案都看得到定義，就能各自實例化；另一種做法是在 .cpp 中做顯式實例化。

9.6可變參數模板與模板模板參數

可變參數模板：任意個數的參數

C++
#include <iostream>
#include <string>

template <typename... T>                       // T... 是「型態參數包」
void count_args(T... args) {                   // args... 是「函數參數包」
    std::cout << "收到 " << sizeof...(args) << " 個參數\n";
}

// C++11 的展開方式：遞迴 + 終止函數
void show() { std::cout << "（結束）\n"; }      // 遞迴終止：沒有參數時呼叫這個

template <typename T, typename... Rest>
void show(const T &first, const Rest &...rest) {
    std::cout << first << " | ";
    show(rest...);                              // 把剩下的參數再交給自己
}

// C++17 的折疊表達式：一行展開
template <typename... Args>
void print(const Args &...args) {
    (std::cout << ... << args) << "\n";
}

template <typename... Args>
auto total(const Args &...args) {
    return (args + ...);                        // 把所有參數加起來
}

int main() {
    count_args();
    count_args(10, 2.2, "abc", 'x');
    show(2330, "TSMC", 1015.0, 'B');
    print("NAV=", 15.32, ", date=", std::string("2026-11-13"));
    std::cout << total(1.5, 2, 3.25) << "\n";
    return 0;
}

收到 4 個參數
2330 | TSMC | 1015 | B | （結束）
NAV=15.32, date=2026-11-13
6.75
  • typename... T 宣告參數包，可以接受零個到任意個參數，型態也可以各不相同。
  • sizeof...(args) 取得參數個數。
  • 展開參數包：C++11 用「處理第一個 + 遞迴處理剩下的 + 一個同名的終止函數」；C++17 有折疊表達式 (std::cout << ... << args)、(args + ...)。
  • 標準程式庫的 std::make_shared<T>(args...)、std::make_unique、std::tuple、std::function 都靠可變參數模板，把參數原封不動轉交給建構函數。

模板模板參數

模板的參數本身也可以是一個模板：

C++
#include <iostream>
#include <vector>
#include <list>
#include <deque>

template <template <typename...> class Container, typename T>   // Container 是「一個模板」
class PriceBuffer {
public:
    void push(const T &x) { data_.push_back(x); }
    T sum() const {
        T s{};
        for (const T &x : data_) s += x;
        return s;
    }
    std::size_t size() const { return data_.size(); }
private:
    Container<T> data_;                          // 用傳進來的模板 + T 組出實際的容器型態
};

int main() {
    PriceBuffer<std::vector, double> a;          // 底層用 vector
    PriceBuffer<std::list, double> b;            // 底層用 list
    PriceBuffer<std::deque, int> c;              // 底層用 deque
    for (double p : {100.0, 101.5, 99.8}) { a.push(p); b.push(p); }
    c.push(3); c.push(4);
    std::cout << a.sum() << " " << b.sum() << " " << c.sum() << " " << c.size() << "\n";
    return 0;
}

301.3 301.3 7 2
  • template <typename...> class Container：Container 不是型態，而是「接受任意型態參數的模板」，可以傳 std::vector、std::list，或自己寫的容器模板。
  • 用途：把「用哪種容器」這類設計決策變成參數，在編譯期組合出類別的行為——老師講義稱為政策式設計（policy-based design）。

9.7綜合範例：泛型的數值工具

把模板和第 5 章「函數當參數」結合，可以寫出不限定型態、也不限定函數種類的數值工具。下面的 newton 接受任何可呼叫物件（lambda、函數、函數物件）——它的型態 F 由編譯器推論，呼叫可以被內聯展開，比 std::function 更快：

C++
#include <iostream>
#include <cmath>
#include <iomanip>

template <typename F, typename DF>
double newton(F f, DF df, double x0, double tol = 1e-12, int max_iter = 100) {
    double x = x0;
    for (int i = 0; i < max_iter; ++i) {
        double step = f(x) / df(x);
        x -= step;
        if (std::abs(step) < tol) return x;
    }
    return x;
}

// Black-Scholes 買權價格與 vega
double norm_cdf(double x) { return 0.5 * std::erfc(-x / std::sqrt(2.0)); }

double bs_call(double S, double K, double r, double T, double sigma) {
    double d1 = (std::log(S / K) + (r + 0.5 * sigma * sigma) * T) / (sigma * std::sqrt(T));
    double d2 = d1 - sigma * std::sqrt(T);
    return S * norm_cdf(d1) - K * std::exp(-r * T) * norm_cdf(d2);
}

double bs_vega(double S, double K, double r, double T, double sigma) {
    double d1 = (std::log(S / K) + (r + 0.5 * sigma * sigma) * T) / (sigma * std::sqrt(T));
    return S * std::sqrt(T) * std::exp(-0.5 * d1 * d1) / std::sqrt(2 * M_PI);
}

int main() {
    double S = 100, K = 105, r = 0.02, T = 0.5, market = 4.20;
    // 隱含波動度：找 sigma 使 BS 價格 = 市價
    auto f  = [&](double s) { return bs_call(S, K, r, T, s) - market; };
    auto df = [&](double s) { return bs_vega(S, K, r, T, s); };
    double iv = newton(f, df, 0.2);
    std::cout << std::setprecision(6) << "隱含波動度 = " << iv * 100 << "%\n";
    std::cout << "驗算：BS 價格 = " << bs_call(S, K, r, T, iv) << "\n";

    // 同一個 newton 也能解 YTM：價格對殖利率的導數用數值差分
    auto bond = [](double y) { double p = 0; for (int t = 1; t <= 5; ++t) p += 3 / std::pow(1 + y, t); return p + 100 / std::pow(1 + y, 5) - 96.5; };
    auto dbond = [&](double y) { return (bond(y + 1e-6) - bond(y - 1e-6)) / 2e-6; };
    std::cout << "YTM = " << newton(bond, dbond, 0.03) * 100 << "%\n";
    return 0;
}

隱含波動度 = 20.775%
驗算：BS 價格 = 4.2
YTM = 3.78137%

（M_PI 是多數編譯器在 <cmath> 提供的圓周率常數；C++20 起可用 <numbers> 的 std::numbers::pi。）

Q1

簡答｜難模板參數 vs std::function

第 5 章的二分法用 const std::function<double(double)> &f 當參數，這裡的牛頓法用模板參數 F f。兩種做法各有什麼優缺點？

答案

std::function 是一個固定的型態，任何可呼叫物件都會被包裝成它，函數本身不必是模板、可以放在 .cpp 分離編譯，也能在執行期存進容器、動態替換；代價是有型態抹除的額外成本，呼叫時無法內聯。模板參數 F 讓編譯器知道確切的型態，對每種 lambda 各實例化一份，呼叫可以被內聯，效率最好；代價是函數必須寫在標頭檔、每種型態都產生一份程式碼，錯誤訊息也較難讀。

9.8本章小結

  • 模板把型態當參數：template <typename T>；編譯期依實際型態實例化出真正的函數或類別。泛型（編譯期）vs 多型（執行期）。
  • 函數模板：從實參自動推論 T；推論失敗時用 f<double>(...) 明確指定；非型態模板參數（必須是編譯期常數）；可以全特化，不能局部特化。
  • 類別模板：使用時寫 Name<T>；類別外定義成員要寫 template <typename T> 與 Name<T>::；可以全特化與局部特化（traits）。
  • typename 用於依賴模板參數的型態名稱；成員函數模板不能是 virtual；using 模板別名。
  • 模板定義通常放標頭檔；或在 .cpp 中顯式實例化。
  • 可變參數模板 typename... T、sizeof...、遞迴展開與 C++17 折疊表達式；模板模板參數把模板當參數（政策式設計）。
